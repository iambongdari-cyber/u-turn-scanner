# U-Turn Scanner — v0.4-5 구현 보고서 (오늘 할 일 섹션 제거)

> **작성일:** 2026-06-13
> **선행:** `V0.4_4_REPORT.md`
> **요청:** `/beginner` 화면에서 "오늘 할 일" (`TodayTodoBox`) 과 "매매계획 기록하기" (`MustSeeSection`) 가 같은 내용을 두 번 보여주는 중복 제거. "오늘 할 일" 섹션 전체 제거.

---

## 1. 구현 요약

v0.4-2 에서 `TodayTodoBox` (오늘 할 일 체크리스트, localStorage 저장) 와 `MustSeeSection` (매매계획 기록하기, 1순위 가로형 + 2/3순위 세로형 카드 + TradePlanButton) 을 모두 도입했지만, 실제 사용해보니 두 영역이 **같은 종목명을 두 번 노출** 하는 결과가 됐습니다. 사용자는 "체크박스 한 번, 카드 한 번" 같은 내용을 두 번 보게 되어 화면이 길어지고 의도가 흐려집니다.

v0.4-5 는 (1) `TopBrief` 컴포넌트에서 `TodayTodoBox` 렌더링과 import 를 제거, (2) 결과적으로 `/beginner` 화면이 **오늘 결론 → 매매계획 기록하기** 순으로 자연스럽게 이어지도록 단순화. 오늘 1순위/시간 있으면 안내는 **오늘 결론 (자연어)** 에 그대로 남고, 실제 액션 (체크 + 매매계획 기록 모달) 은 **매매계획 기록하기 카드** 에 집중. GPT 리포트의 `## 1. 오늘 할 일` 섹션 명칭은 그대로 유지 (사용자 명세 §4).

후보 선정 / 오늘 결론 로직 / 매매계획 기록 / TradePlan 저장 / 지난 투자판단 달력 / GPT 리포트 / 스캔 산식 / 키움 API / Supabase write / 자동매매 — 모두 변경 0건.

## 3. 오늘 할 일 섹션 제거 내용
