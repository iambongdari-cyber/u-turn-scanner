# U-Turn Scanner — v0.7.6.3 핫픽스 보고서 (GPT 리포트 본문 pre → textarea 변경)

> **작성일:** 2026-06-13
> **선행:** `V0.7_6_2_REPORT.md`
> **문제:** v0.7.6.2 에서 4 단계 wrapper 에 `min-w-0 / max-w-full / overflow-hidden` 균일 적용했지만 PC 에서 [GPT 상담용 리포트 보기/복사] 클릭 시 여전히 페이지가 가로로 확장. CSS 기반 보정으로는 `<pre>` 의 contents intrinsic 가로폭 문제 완전 차단 불가.

---

## 1. 원인 재분석

`<pre>` 는 본질적으로 "긴 contents 를 그대로 표시" 하는 인라인 블록 요소. `whiteSpace: pre-wrap` + `overflowWrap: anywhere` 를 적용해도 일부 브라우저 / 일부 콘텐츠 조합에서 contents 의 intrinsic 가로폭이 부모를 밀어내는 경우가 발생. 4 단계 wrapper 의 `overflow-hidden` 이 그 너머의 contents 를 잘라야 하지만, 일부 케이스에서는 부모의 가로폭 계산 자체가 contents 기준으로 일어남.

**근본 해결:** `<pre>` 사용 자체를 포기하고 **`<textarea readOnly>`** 로 교체. textarea 는 native form element 라 **자체적으로 부모 가로폭 안에 자기 영역을 가둠**. contents 가 아무리 길어도 textarea 박스 자체는 절대 부모를 넘지 않으며, 긴 텍스트는 textarea 내부에서 자동 줄바꿈 또는 내부 스크롤로 처리됨.

## 2. textarea 의 장점

| 비교 | `<pre>` (이전) | `<textarea readOnly>` (v0.7.6.3) |
|---|---|---|
| 부모 가로폭 침범 | 가능 (contents intrinsic 문제) | **불가능** (native form element 의 자기 영역 격리) |
| 가로 스크롤 | 외부 (페이지 가로 확장) | **내부** (textarea 자기 영역 안) |
| 세로 크기 제어 | `max-h` + `overflow-y-auto` | **`height: 520px`** 명시 + `resize: y` 사용자 조절 |
| 전체 선택 | `Range + selectNodeContents` 복잡 | **`textarea.select() + setSelectionRange()`** 단순 |
| 사용자 직접 편집 | (불가) | **`readOnly`** 로 차단 (보기/복사 전용) |
| 가독성 (모노스페이스) | 동일 | 동일 (`font-mono`) |
| 모바일 길게 눌러 복사 | 가능 | 가능 (동일) |
| Ctrl+A / Ctrl+C | 영역 안 자동 | **textarea 안에서 자동** (네이티브) |

## 3. 적용한 textarea 속성 (사용자 명세 §2 그대로)

```tsx
<textarea
  ref={textareaRef}
  readOnly
  value={markdown}
  className="block w-full min-w-0 max-w-full box-border resize-y
             rounded-md border border-slate-200 bg-slate-50 p-3
             font-mono text-[13px] leading-relaxed text-slate-800 sm:text-[14px]"
  style={{
    height: '520px',
    maxWidth: '100%',
    whiteSpace: 'pre-wrap',
    overflowWrap: 'anywhere',
    wordBreak: 'break-word',
    overflowX: 'auto',
    overflowY: 'auto',
    userSelect: 'text',
    WebkitUserSelect: 'text',
  }}
/>
```

핵심:
- **`readOnly`** — 사용자가 편집 못함, 보기/복사 전용
- **`value={markdown}`** — children 으로 줘도 되지만 controlled value 가 더 명확
- **`height: 520px`** — 인라인 펼침에서 카드 안 적절한 세로 크기
- **`resize: y`** — 사용자가 세로 크기 직접 조절 가능 (PC 편의)
- **`block w-full min-w-0 max-w-full box-border`** — 부모 가로폭 안에 안전하게 배치
- **`overflowWrap: anywhere` + `wordBreak: break-word`** — 긴 토큰 자동 줄바꿈
- **`whiteSpace: pre-wrap`** — 마크다운 줄바꿈 보존

### 5-2. [전체 선택] (사용자 명세 §4)
```ts
selectAllReportText() {
  const ta = textareaRef.current;
  ta.focus();                            // 1) 포커스
  ta.select();                            // 2) 전체 선택
  ta.setSelectionRange(0, ta.value.length); // 3) 명시적 range 설정 (iOS 호환)
  ta.scrollIntoView({ behavior: 'smooth' });
  // userAgent 분기 안내 ("Ctrl+C" / "길게 눌러 복사")
}
```
