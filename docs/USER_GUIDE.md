# U턴스캐너 사용설명서

> 버전 기준: v0.7.6.3
> 마지막 갱신: 2026-06-13

---

## 1. U턴스캐너는 무엇인가

U턴스캐너는 **종목 추천기가 아니라, 오늘 내가 어떤 투자 행동을 해야 할지 정리해주는 개인 기록용 투자 코치**입니다.

### 1-1. U턴스캐너가 하는 일
- 오늘 시장 상태를 점수로 평가합니다
- 그 시장 상태에 맞는 전략 모드(공격/선별/방어/관망)를 안내합니다
- 매매계획(예약매수가 / 목표가 / 손절가)을 기록할 수 있게 도와줍니다
- 키움에서 체결된 결과를 입력하면 보유종목으로 관리해 줍니다
- 매도완료 시 결과를 누적해서 전략 컨디션(승률·기대수익)을 계산합니다
- ChatGPT 에게 그대로 붙여넣을 수 있는 상담용 리포트를 만들어 줍니다

### 1-2. U턴스캐너가 하지 않는 일 (중요)
- ❌ **자동매매가 아닙니다.** 어떤 매수/매도 주문도 자동으로 들어가지 않습니다.
- ❌ **실제 주문 기능이 없습니다.** 화면의 모든 버튼은 "기록" 또는 "상태 변경" 용입니다.
- ❌ **키움 API 연동이 없습니다.** 키움 예약매수는 사용자가 **직접 키움에서 입력**해야 합니다.
- ❌ **U턴스캐너가 매수/매도를 시키지 않습니다.** 모든 화면 안내는 참고용입니다.

### 1-3. 최종 판단은 사용자 본인
화면에 표시되는 모든 안내(시장 상태, 전략 모드, 1순위 종목, 추천/금지 행동, GPT 리포트)는 **개인 기록용 AI 판단**입니다. **실제 매수/매도 결정과 키움 입력은 사용자 본인이 합니다.** 투자 손익에 대한 책임은 사용자 본인에게 있습니다.

## 2. 하루 사용 흐름

> 출근 전 또는 퇴근 후 10분이면 충분합니다.

| 순서 | 단계 | 어디서 |
|---|---|---|
| 1 | `/beginner` 화면 접속 | 브라우저 |
| 2 | **오늘의 결론** 확인 — 오늘의 태도 / 시장 상태 / 전략 모드 / 1순위 종목 | 화면 §0 |
| 3 | **시장 상태** 확인 — 점수 / 판단 사유 | 화면 §1 |
| 4 | **전략 컨디션** 확인 — 내 전략이 최근 먹히는지 | 화면 §2 |
| 5 | **매매계획 기록하기** 카드의 [매매 계획 기록] 클릭 → 1차/2차 매수가, 목표가, 손절가 입력 | 화면 §3 |
| 6 | 종목이 자동으로 **내 예약매수 대기** 섹션으로 이동 | 화면 §4 |
| 7 | **키움 HTS/MTS 에서 직접 예약매수 입력** (U턴스캐너 외부 작업) | 키움 |
| 8 | 체결되면 화면에서 [1차 체결] 또는 [2차 체결] 버튼 클릭 + 실제 체결가 입력 | 화면 §4 |
| 9 | 종목이 자동으로 **내 보유종목 점검** 섹션으로 이동 | 화면 §5 |
| 10 | 매도 시점에 [매도완료] 클릭 → 실제 종료가 + 종료일 + 메모 입력 | 화면 §5 |
| 11 | 전략 컨디션에 자동 누적 (5건 이상부터 승률·기대수익 계산) | 화면 §2 |
| 12 | ChatGPT 추가 상담이 필요하면 [GPT 상담용 리포트 보기/복사] 클릭 | 화면 §8 |

## 3. 오늘의 결론 보는 법 (화면 §0)

화면 가장 위에 있는 자연어 안내 영역입니다. 매일 가장 먼저 확인합니다.

### 3-1. 표시 항목
| 항목 | 의미 |
|---|---|
| **오늘의 태도** | 공격 매매 / 선별 매매 / 방어 매매 / 관망 — 오늘 매매 강도 |
| **시장 상태** | 강세장 / 보합장 / 약세장 / 위험구간 (+ 점수) |
| **전략 모드** | 공격 / 선별 / 방어 / 관망 |
| **자연어 안내 2~3 줄** | 오늘 몇 종목만 봐야 하는지, 현금 비중 권장 |
| **핵심 문장** | 오늘 시장의 한 줄 코치 메시지 |

### 3-2. 예시
```
📋 오늘의 결론
오늘의 태도: 선별 매매
시장 상태: 보합장 62점
전략 모드: 선별

오늘은 NAVER 1개만 검토하세요.
예약매수는 최대 1건만 허용하고,
현금 비중 50% 이상을 유지하세요.

💡 강한 종목만 선별해야 하는 날입니다.
```

→ "오늘은 NAVER 1개만 검토하세요" 는 **오늘 행동 대상은 NAVER 1개** 라는 뜻입니다. 다른 종목에 한눈팔지 않습니다.

### 3-3. 1순위 종목이 없는 날
시장 상태가 위험구간이거나 강한 신규 후보가 없으면:
```
오늘은 신규 진입보다 관망이 우선입니다.
예약매수 대기 / 보유종목 점검에 집중하세요.
```
이런 날은 **신규 매수 보류**가 정답입니다.

## 4. 시장 상태 보는 법 (화면 §1)

### 4-1. 4 단계 시장 상태

| 점수 | 시장 상태 | 전략 모드 |
|---|---|---|
| **80~100** | 강세장 | 공격 |
| **60~79** | 보합장 | 선별 |
| **40~59** | 약세장 | 방어 |
| **0~39** | 위험구간 | 관망 |

### 4-2. 시장 상태 박스 표시
- 시장 상태 라벨 + 점수
- 전략 모드 뱃지
- 한 줄 안내
- 판단 사유 칩 (예: "KOSPI 60일선 위", "KOSDAQ 20일 -12.6%")
- [자세히 보기 ▾] 토글

[자세히 보기 ▾] 안에 점수 기준표 / 시그널 표 / 추천 행동 / 금지 행동이 모두 들어 있습니다. 필요할 때만 펼쳐서 확인합니다.

### 4-3. 주의
시장 상태는 사이드카 데이터로 자동 산출한 **참고용 판단**입니다. 실제 진입 여부는 사용자가 직접 결정합니다.

## 5. 전략 컨디션 보는 법 (화면 §2)

### 5-1. 무엇인가
내 U턴 전략이 최근에 잘 먹히고 있는지를 보는 영역입니다. 매도완료 결과를 누적해서 자동 계산합니다.

### 5-2. 처음에는 데이터 부족
사용 시작 직후에는 매도완료 결과가 없으므로:
```
🧭 전략 컨디션      [상태: 데이터 부족]  [신뢰도: 계산 안 함]
현재 누적 매매: 0건 / 목표 20건
```

### 5-3. 신뢰도 기준 (누적 건수 기준)
| 누적 건수 | 신뢰도 |
|---|---|
| **0~4건** | 계산 안 함 |
| **5~9건** | 낮음 |
| **10~19건** | 보통 |
| **20건 이상** | 높음 |

### 5-4. 계산되면 표시되는 항목
| 항목 | 의미 |
|---|---|
| 승률 | 최근 20건 중 수익 종결 비율 (%) |
| 평균 수익률 | 수익으로 끝낸 종목들의 평균 (+ %) |
| 평균 손실률 | 손실로 끝낸 종목들의 평균 (- %) |
| 기대수익 | 승률 × 평균수익 + (1-승률) × 평균손실 |
| 전략 상태 | 매우 좋음 / 좋음 / 보통 / 주의 / 위험 |

### 5-5. 등급별 안내
| 등급 | 의미 |
|---|---|
| 매우 좋음 (70%+) | 전략이 매우 잘 작동 — 현 모드 유지 |
| 좋음 (60~69%) | 잘 작동 중 — 시장 모드 추천대로 진행 |
| 보통 (50~59%) | 평균 수준 — 손절 원칙 더 엄격하게 |
| 주의 (40~49%) | 흔들리는 중 — 신규 진입 강도 하향 |
| 위험 (40% 미만) | 작동 안 함 — 신규 진입 보류 + 손실 패턴 회고 |

### 5-6. 주의
- 매도완료 후 **실제 종료가 입력**이 있어야 계산됩니다
- 매도완료 했지만 결과를 입력 안 한 종목은 자동 제외됩니다
- 결과 미입력이 많으면 화면에 "※ 결과 미입력 N건" 안내가 뜹니다

## 6. 매매계획 기록하기 (화면 §3)

오늘의 결론에서 안내한 1순위 종목을 실제로 기록하는 영역입니다.

### 6-1. 카드 표시 항목
| 항목 | 의미 |
|---|---|
| 종목명 / 티커 | 예: 시프트업 (462870) |
| AI 판단 | 매수 / 관찰 / 보유 / ... |
| 위험도 | 낮음 / 보통 / 높음 |
| U턴 점수 | 5개 조건 중 N개 충족 |
| 현재가 | 최근 종가 |
| 핵심 이유 | U턴 신호 / 거래대금 회복 / 60일선 회복 등 |

### 6-2. [매매 계획 기록] 버튼 클릭 시
모달이 열리면서 다음 항목을 입력합니다:
- **1차 예약매수가** + 이유 (자동 제안: 현재가)
- **2차 예약매수가** (선택) + 이유 (자동 제안: 60일선 +2%)
- **목표 매도가** + 이유 (자동 제안: 60일선 +20%)
- **손절 기준가** + 이유 (자동 제안: 60일선 -5%)
- AI 판단 (관찰/매수/...) + 매수 추천 이유
- 사용자 메모 (선택)

[기록하기] 클릭 시:
- 종목이 **내 예약매수 대기 목록**으로 이동합니다
- **실제 주문은 발생하지 않습니다**
- **키움 예약매수는 사용자가 직접 키움 HTS/MTS 에서 입력**해야 합니다

## 7. 내 예약매수 대기 (화면 §4)

내가 매매계획을 기록해둔 종목들이 보이는 영역입니다.

### 7-1. 표시 항목
- 종목명
- 1차 예약가 / 2차 예약가
- 현재가 / 예약가와의 차이
- AI 판단: 예약 유지 / 예약 취소 / 가격 재검토
- 오늘 행동 가이드

### 7-2. 버튼
| 버튼 | 동작 |
|---|---|
| [미체결] | 아직 키움에서 체결 안 됨 — 현재 상태 유지 |
| [1차 체결] | 1차 예약매수가에 체결됨 → 실제 체결가 입력 → 보유종목으로 이동 |
| [2차 체결] | 2차 예약매수가에도 체결됨 → 실제 체결가 입력 → 평균매수가 자동 계산 |
| [취소] | 예약을 취소했음 → 사유 입력 |

### 7-3. ⚠ 가장 중요한 주의
**U턴스캐너는 키움에 자동으로 주문을 넣지 않습니다.**
- 매매계획을 기록한 후, **키움 HTS/MTS 를 직접 열어** 예약매수를 사용자가 손으로 입력해야 합니다
- 체결되면 화면에 와서 [1차 체결] 또는 [2차 체결] 버튼을 사용자가 직접 클릭합니다
- 실제 체결가를 입력하지 않으면 평균매수가가 계산 안 됩니다

## 8. 내 보유종목 점검 (화면 §5)

체결 처리된 종목이 보유종목으로 표시됩니다.

### 8-1. 표시 항목
| 항목 | 의미 |
|---|---|
| 종목명 / 체결 상태 | 1차 체결 / 2차 체결 / 보유중 |
| 평균 매수가 | 1차/2차 체결가 평균 |
| 현재가 / 수익률 | 사이드카 close 기준 |
| 목표 매도가 / 손절 기준가 | 기록 시 입력한 값 (수정 가능) |
| AI 판단 | 보유 / 일부매도 / 매도 / 추가매수 대기 |
| 오늘 행동 가이드 | 오늘 할 일 체크리스트 |

### 8-2. 버튼
| 버튼 | 동작 |
|---|---|
| [목표가 수정] | 변경 사유 필수 입력 후 저장 (이력 누적) |
| [손절가 수정] | 변경 사유 필수 입력 후 저장 |
| [보유중] | 그대로 보유 |
| [2차 체결 추가] | 1차 체결 후 2차도 들어옴 |
| [일부매도] | 일부 차익실현 |
| [매도완료] | 전량 종료 → 결과 입력 모달 (다음 섹션) |

### 8-3. 추가매수 검토 4 조건
보유 종목 카드 안에 추가매수 검토 영역이 표시됩니다:
- 1차 매수가 위 유지
- 거래량 급감 없이 눌림
- 60일선 또는 지지선 이탈 없음
- 총 투자금 한도 초과 없음 (사용자 직접 체크)

4 개 모두 충족 시 "추가매수 검토 가능" / 2~3 개 충족 시 "추가매수 대기" / 0~1 개 "추가매수 금지" 안내가 뜹니다.

## 9. 매도완료와 전략 컨디션 반영

### 9-1. 매도완료 흐름
보유종목 카드의 [매도완료] 클릭 → 모달이 열림 → 다음 입력:

| 입력 | 설명 |
|---|---|
| **실제 종료가** (필수) | 키움에서 매도된 가격 |
| 자동 계산 수익률 | (종료가 - 평균매수가) / 평균매수가 × 100 |
| 수익률 직접 수정 (선택) | 부분 매도 평균가 등 사용자 직접 입력 가능 |
| **종료일** (필수) | 기본값: 오늘 |
| 메모 (선택) | "목표가 도달 후 일부매도 + 잔여 매도" 등 |

[매도완료 기록] 클릭 → status: 매도완료 + 결과 4 필드 채워짐.

### 9-2. 전략 컨디션 자동 반영
- 매도완료 결과가 입력되면 **전략 컨디션 카드의 누적 매매 카운트가 +1** 됩니다
- 5건 이상 누적되면 **승률·평균수익·기대수익이 자동 계산**됩니다
- 20건 이상 누적되면 **신뢰도가 "높음"** 으로 올라갑니다

### 9-3. 주의
- 매도완료 기록 없이 보유종목에서 사라지게 하면 전략 컨디션 데이터가 누적 안 됩니다
- 부분 매도의 경우 사용자가 직접 수익률을 수정해 정확하게 기록하세요
- 손실 매매도 반드시 기록 — 패턴 회고에 필요합니다

## 10. 관심 후보 / 참고 후보 (화면 §6)

### 10-1. 관심 후보
- 오늘 신호가 약하지만 흐름 변화가 있는 종목
- AI 판단 "관찰" 단계
- **오늘 행동 대상은 아닙니다**

## 13. 초보자 사용 원칙

다음 6 원칙을 매일 지키세요. 화면이 길게 설명해도 결국 이 6 가지가 핵심입니다.

### 원칙 1 — 하루에 1순위만 본다
오늘의 결론에서 안내된 1순위 종목 외에는 신경 쓰지 않습니다. 매매계획 기록도 보합장에서는 1 개만, 강세장에서도 최대 3 개입니다.

### 원칙 2 — 손절가 없이 매수하지 않는다
매매 계획 기록 모달에서 손절 기준가를 반드시 입력합니다. 손절가가 명확하지 않으면 매매계획 자체를 보류합니다.

### 원칙 3 — 키움 주문은 직접 입력한다
U턴스캐너는 자동매매가 아닙니다. 매매계획 기록 후 **키움 HTS/MTS 를 직접 열어** 예약매수를 손으로 입력합니다. 체결되면 다시 와서 [1차 체결] / [2차 체결] 버튼을 클릭합니다.

### 원칙 4 — 여러 종목을 동시에 보지 않는다
신규 매매계획 기록 대상은 1~3 개 캡. 보유/예약 합쳐서 동시에 너무 많은 종목을 들고 있지 않습니다.

### 원칙 5 — 전략 컨디션이 데이터 부족일 때는 무리하지 않는다
신뢰도가 "계산 안 함" 또는 "낮음" 일 때는 시장 모드 추천대로만 진행합니다. 욕심 부려서 캡을 초과하지 않습니다.

### 원칙 6 — 매매 결과를 반드시 기록한다
매도완료 시 결과를 입력하지 않으면 전략 컨디션이 누적되지 않아 평생 "데이터 부족" 상태가 됩니다. 손실 매매도 반드시 기록 — 패턴 회고에 필요합니다.

## 14. 자주 하는 실수 (꼭 피하세요)

처음 사용하는 사용자가 가장 자주 저지르는 실수입니다. 미리 알고 피하면 손실 확률이 크게 줄어듭니다.

### 실수 1 — 매매계획만 기록하고 키움 입력을 안 함
- 매매계획 기록 = U턴스캐너 안 기록
- 실제 예약매수 = 키움에서 사용자가 직접 입력
- 키움 입력을 잊으면 1차 체결 자체가 안 일어남
- **해결:** 매매계획 기록 직후 키움 HTS/MTS 를 곧바로 열어서 예약매수 입력

### 실수 2 — 체결됐는데 화면에서 [1차 체결] 버튼 안 누름
- 키움에서 체결됐어도 U턴스캐너 화면은 모름
- [1차 체결] 안 누르면 예약매수 대기 상태로 남음
- 보유종목 점검 영역에서 안 보임
- 평균매수가 / 수익률 계산 안 됨
- **해결:** 키움 체결 알림 받으면 즉시 화면 와서 [1차 체결] / [2차 체결] 클릭 + 실제 체결가 입력

### 실수 3 — 매도완료 시 결과 입력 안 함
- [매도완료] 클릭만 하고 모달 입력 안 하면 결과 4 필드가 비어 있음
- 전략 컨디션 계산에서 자동 제외됨
- 화면에 "※ 결과 미입력 N건" 안내가 누적됨
- **해결:** 매도 직후 종료가 + 종료일 + 메모 반드시 입력

### 실수 4 — 손절가 없이 매매계획 기록
- 손절가 = 가장 중요한 숫자
- 손절가 없으면 손실 확대 막을 수 없음
- 매매계획 기록 모달에서 손절 기준가 필드를 0 으로 두지 마세요
- **해결:** 손절가가 명확히 안 떠오르면 매매계획 기록 자체를 보류

### 실수 5 — 1순위 아닌 종목 매매
- "오늘의 결론" 이 안내한 1순위 종목 외에는 매매 X
- "이 종목도 좋아 보여서" 라는 이유로 동시에 여러 종목 매수 금지
- 강세장이라도 캡 최대 3 개
- **해결:** 오늘의 결론 화면을 다시 읽고 1순위만 매매

### 실수 6 — 위험구간/위험 컨디션에서 무리한 진입
- 시장 상태 0~39 위험구간 = 신규 진입 금지
- 전략 컨디션 위험 = 시장 모드 무관 신규 0 개
- 화면이 매매계획 기록 대상을 0 개로 표시하면 진짜 0 개
- "이번엔 다르겠지" 가 가장 위험한 생각
- **해결:** 화면이 0 개라고 하면 그대로 따름

### 실수 7 — 전략 컨디션 데이터 부족 단계에서 캡 초과
- 신뢰도 "계산 안 함" / "낮음" 단계에서는 컨디션 수치를 신뢰하지 않음
- 시장 모드 추천대로만 진행
- 5~9건 누적 단계는 표본이 적어 변동성 큼
- **해결:** 데이터 부족 단계에서는 시장 모드 캡을 그대로 따름 (욕심 X)

### 실수 8 — GPT 응답을 절대 정답으로 받아들임
- ChatGPT 응답은 추가 참고용일 뿐
- "ChatGPT 가 사라고 했으니까" 는 매매 사유 아님
- U턴스캐너 화면의 1순위 + 사용자 본인의 판단이 우선
- **해결:** GPT 응답과 화면 안내가 다르면 화면 안내를 따름

### 실수 9 — 매도완료 결과 누락한 채 다음 매매로 넘어감
- 손실 매매를 기록 안 하면 승률이 부정확
- 전략 컨디션이 계속 데이터 부족 상태
- 자기 매매 패턴 회고 불가
- **해결:** 손실/이익 무관하게 모든 매도완료 결과 기록

### 실수 10 — 같은 종목에 물타기
- 보유 종목이 손절가 가까이 떨어지는데 평균단가 낮추려고 추가매수
- 추가매수 4 조건 미충족인데도 진입
- "지금이 기회" 라는 감정 기반 결정
- **해결:** 추가매수 검토 영역의 4 조건 자동 평가 결과를 따름. 4/4 미만이면 추가매수 보류

## 15. 테스트 체크리스트

처음 사용해보면서 다음 순서대로 체크해보세요. 모든 단계가 정상 동작해야 합니다.

| # | 단계 | 기대 동작 |
|---|---|---|
| 1 | `/beginner` 진입 | 오늘의 결론 / 시장 상태 / 전략 컨디션 / 매매계획 기록하기 순으로 보임 |
| 2 | 오늘의 결론 확인 | 1순위 종목명이 매매계획 기록하기 카드의 첫 종목과 일치 |
| 3 | 매매계획 기록 카드의 [매매 계획 기록] 클릭 | 28 필드 입력 모달 열림 + 기본값 자동 제안 |
| 4 | 1차/2차 매수가, 목표가, 손절가 + 이유 입력 후 [기록하기] | "✓ 매매 계획 기록됨" 뱃지 표시 |
| 5 | 화면 새로고침 | 종목이 **내 예약매수 대기** 섹션에 표시됨 |
| 6 | 예약매수 대기 카드의 [1차 체결] 클릭 + 실제 체결가 입력 | 종목이 **내 보유종목 점검** 섹션으로 이동 |
| 7 | 보유종목 카드의 [매도완료] 클릭 | CloseTradeModal 모달 열림 |
| 8 | 실제 종료가 입력 | 자동 수익률 계산 표시 |
| 9 | 종료일 + 메모 입력 후 [매도완료 기록] | 종목이 매도완료 상태로 변경 |
| 10 | 전략 컨디션 카드 확인 | 누적 매매 카운트가 +1 됨 |
| 11 | 5건 이상 누적 후 전략 컨디션 카드 확인 | 승률·평균수익·기대수익 표시 + 신뢰도 "낮음" |

| 13 | 본문 복사 → ChatGPT 에 붙여넣기 | 마크다운 그대로 정상 표시 |
| 14 | 어제 날짜 클릭 (지난 투자판단 달력) | `/beginner?date=YYYY-MM-DD` 로 이동 |

## 16. 중요 안내 (다시 강조)

- ✅ U턴스캐너는 **투자 참고용 개인 기록 도구**입니다
- ❌ **자동매매가 아닙니다**
- ❌ **실제 주문 기능이 없습니다**
- ⚠ **키움 예약매수는 사용자가 직접 입력**해야 합니다
- ⚠ **모든 화면 안내는 참고용**이며 실제 매수/매도/예약/취소는 키움에서 사용자가 합니다
- ⚠ **투자 손익에 대한 책임은 사용자 본인에게 있습니다**
- ⚠ U턴스캐너의 시장 상태/전략 모드/AI 판단/GPT 리포트는 모두 자동 분석 결과이며 절대적인 정답이 아닙니다
