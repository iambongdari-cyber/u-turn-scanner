## 0. 작업 범위 (요약)

5가지 화면 보정만 수행한다. 데이터·DB·핵심 스캔 로직·사이드카 산출 기준은 모두 그대로.

1. 홈 화면 흐름 재배치 — 버전 그룹 → 사용자 하루 흐름 그룹(오늘 시작 → 후보 점검 → 입력 참고 → 복기 → 기존 기능)
2. `/leaders` 상단 노란 경고 박스 — "🥇 진짜 주도주 후보" 라벨이 매수 권유처럼 보이지 않도록
3. `/bottom-watch` 단계별 카드 수 제한(기본 10 + 더 보기) + 정렬 안내
4. `/leaders` 분류별 카드 수 제한(기본 5 + 더 보기) — `<details>` 접힘 사용
5. `/journal` 일지 초안 박스 상단에 역할 안내(자유 메모와의 분리)

## 5. `/leaders` 경고 문구 보강 내용

`header` 직후, 요약 카드 섹션보다 **먼저** 등장하는 노란 박스(`border-amber-300 bg-amber-50`) 1개를 추가:

> 🥇 **진짜 주도주 후보**는 돈의 흐름과 가격 위치를 함께 본 분류입니다. **매수 권유가 아니며**, 가격 진입 여부는 사용자 본인이 **추격 위험**과 함께 판단해야 합니다. 기본 노출은 거래대금·전고점 근접도·상대강도 기준 상위 종목 위주이며, 나머지는 "더 보기"로 펼치세요.

위치를 **요약 카드보다 앞**으로 잡은 이유: 사용자가 "🥇" 카드를 보기 전에 톤이 잡히도록.

기존 하단 안내 박스("이 화면은 '오늘 살 종목' 추천 화면이 아닙니다…")는 그대로 유지 → 진입 시점·이탈 시점 모두 톤 강화.

## 6. `/bottom-watch` 카드 수 제한 방식

### 정렬 안내 (상단)
요약 카드 섹션 직후, 단계 섹션이 시작되기 전에 회색 한 줄 안내:
> 기본 노출은 거래대금 회복과 U턴 근거가 뚜렷한 종목을 우선으로 보여줍니다. 각 단계별 최대 10개이며, 나머지는 "더 보기"로 펼치세요.

### `StageSection` 컴포넌트 보강
- 상수: `STAGE_DEFAULT_LIMIT = 10`
- 동작: `items.slice(0, 10)`을 기본 노출, 나머지는 `<details><summary>나머지 N개 더 보기</summary>…</details>` 안에서 펼침.
- 정렬은 `scan_dump.py`가 이미 `days_below_ma60` 내림차순 + `value_ratio` 내림차순으로 떨군 그대로 사용. 화면에서는 **slice만** 한다.

### 적용 범위
4개 단계 섹션(바닥 관찰 / U턴 시도 / U턴 확인 / 추세전환 후보) 전부에 동일 적용. 다른 화면 요소(요약 카드, 종목 카드 내부 구조, 하단 톤 박스)는 변경 없음.

## 7. `/leaders` 카드 수 제한 방식

### `SubSection` 컴포넌트 보강
- 상수: `SECTOR_MEMBER_LIMIT = 5`
- 동작: 각 분류 섹션(진짜 주도주 후보 / 후발주 관찰 / 기회 후보 / 추격 위험)에서 `items.slice(0, 5)`만 기본 노출. 나머지는 `<details>` 접힘 안에 `나머지 N개 더 보기`로 펼침.
- 정렬은 `sector_dump.py`가 분류별로 다르게 떨군 그대로:
  - 진짜 주도주 후보: 전고점 근접도 → 거래대금 내림차순
  - 후발주 관찰 / 기회 후보: 20일 수익률 내림차순
  - 추격 위험: 이격도 내림차순

### 약한 섹터 접힘 유지
`sectors_weak`을 페이지 하단 `<details>` 접힘으로 처리한 기존 구조는 변경 없음. v0.2-3에서 정한 톤 그대로.

- 헤더 아래 노란 경고 박스가 강한 섹터 카드보다 먼저 보임
- 강한 섹터 카드 각 분류(🥇 진짜 주도주 후보 / 🥈 후발주 관찰 / 🎯 기회 후보 / ⚠️ 추격 위험)에서 기본 5개만 표시
- 5개를 초과하는 분류에 "나머지 N개 더 보기" 접힘 표시 → 클릭 시 펼침
- 약한 섹터는 페이지 하단에 접힘 유지

### `/bottom-watch`
- 요약 카드 아래에 회색 정렬 안내 한 줄 보임
- 4개 단계 섹션 각각 기본 10개 + "나머지 N개 더 보기"

### `/journal`
- 각 메모 카드의 보라색 "일지 초안 — 관찰·복기 보조" 박스 제목 바로 아래에 "이 박스는 사이드카 분석에서 자동으로 채워지는 초안입니다. 사용자 본인의 판단·근거는 아래 자유 메모에 따로 적어 주세요." 안내 표시
- 기존 4가지 라인(오늘 분류 / 확인 근거 / 조심할 점 / 다음 복기 때 볼 것) 그대로

### 회귀 확인
- 기존 12개 화면 회귀 없음
  - `/reports/[id]`, `/stocks/[ticker]`, `/backtest`, `/alerts`, `/history`, `/search`
  - `/market`, `/opportunities`, `/kiwoom-helper`
  - `/bottom-watch`, `/leaders`, `/journal` (보강 후에도 기본 흐름 정상)

## 부록 — 화면 톤 원칙 재확인

### 홈
"오늘 처음 켰을 때 어디부터 봐야 하는가"를 **순서로 보여준다.** 색깔 그룹 구분 대신 1→2→3→4→5 번호와 짧은 설명으로 흐름을 안내. 자동 추천이 아닌 **체크리스트** 톤.

### `/leaders`
"오늘 살 종목" 인상을 막기 위해 **카드를 보기 전에** 노란 경고가 먼저 보이는 위치로 배치. 카드는 분류별 5개만 노출해 **첫 시야에 시각 자극이 폭발하지 않게.**

### `/bottom-watch`
"많이 빠진 종목 추천" 인상을 막기 위해 정렬 안내("거래대금 회복과 U턴 근거가 뚜렷한 종목을 우선")를 미리 표시. 카드는 단계별 10개만 노출해 **사용자가 압도되지 않게.**

### `/journal`
일지 초안 박스가 자동 초안임을 명시해 **사용자의 자유 메모와 역할이 분리**됨을 강조. 자동/수동 메모가 한 카드 안에 공존하더라도 책임 영역이 다름을 화면에서 분명히.
