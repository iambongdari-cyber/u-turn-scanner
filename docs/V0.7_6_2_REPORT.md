## 1. 원인

`<pre>` 안의 마크다운에는 코드/링크/긴 영어 단어/괄호 묶인 종목명 등 줄바꿈이 자연스럽지 않은 토큰이 들어있음. `whitespace: pre-wrap` 만 있으면 단어 단위로 줄바꿈하므로 단일 단어가 부모 너비를 넘는 경우 컨테이너를 가로로 확장.

추가로 부모 wrapper 가 **flex 컨테이너** (`<div className="flex flex-wrap gap-2">`) 안에 들어있는데, flex item 의 기본값은 `min-width: auto` 라서 자식 컨텐츠의 최소 가로폭만큼 자동으로 커짐. 부모에 명시적으로 `min-w-0` 가 없으면 자식 wrapper 가 자기 contents 의 가로폭을 강요함.

## 2. 적용한 가로폭 제어

### 2-1. 4 단계 wrapping (사용자 명세 §2 §3 §4)

```
page.tsx PC wrapper
  └─ flex 컨테이너
       └─ GptReportButton 루트 wrapper (this 컴포넌트 진입)
            └─ ready phase 펼침 영역 wrapper
                 └─ 본문 컨테이너 div
                      └─ <pre> 본문
```

각 wrapper 에 다음 클래스를 균일하게 적용:

| wrapper | 적용 클래스 |
|---|---|
| `page.tsx` PC `<div className="hidden md:block">` | **`min-w-0 max-w-full overflow-hidden`** |
| `page.tsx` 안 flex 컨테이너 `<div className="flex flex-wrap gap-2">` | **`min-w-0 max-w-full`** |
| `GptReportButton` 루트 `<div className="w-full">` | **`min-w-0 max-w-full overflow-hidden`** |
| ready phase 펼침 영역 `<div className="rounded-lg ...">` | **`w-full min-w-0 max-w-full overflow-hidden`** |
| 본문 컨테이너 `<div className="px-4 py-3">` | **`min-w-0 max-w-full overflow-hidden`** |
| `<pre>` 본문 | **`w-full min-w-0 max-w-full max-h-[60vh] overflow-x-auto overflow-y-auto`** + style `overflowWrap: 'anywhere'` |

### 2-2. 핵심 토픽 — flex item 의 `min-w-0`

CSS flexbox 사양상 flex item 은 `min-width: auto` 가 기본값이라 자식 contents 의 intrinsic 최소 가로폭으로 확장됨. `min-w-0` (= `min-width: 0`) 을 명시하면 자식 wrapping/overflow 가 동작 시작.

→ flex 컨테이너 안의 모든 직계 자식에 `min-w-0` 명시.

### 2-3. `<pre>` 본문의 줄바꿈 정책

| 속성 | 값 | 효과 |
|---|---|---|
| `whiteSpace` | `'pre-wrap'` | 줄바꿈 보존 + 단어 단위 자동 줄바꿈 |
| `wordBreak` | `'break-word'` | 긴 단어 자동 줄바꿈 |
| `overflowWrap` | `'anywhere'` | 어떤 지점에서든 줄바꿈 가능 (URL, base64 등도 줄바꿈) |
| `overflow-x-auto` | (Tailwind) | 그래도 가로로 넘치면 내부 스크롤바 노출 |

이 4 조합으로 마크다운 안의 어떤 토큰도 본문 영역을 가로로 확장하지 않음. `break-all` 은 한국어 자연 어절을 깰 수 있어서 회피, `overflow-wrap: anywhere` + `word-break: break-word` 조합으로 충분.
