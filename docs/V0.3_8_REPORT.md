### 섹션 헤더
- **제목**: "핵심 변화 종목 빠르게 보기"
- **설명**: "표를 끝까지 보지 않아도 직전 스냅샷 대비 핵심 변화 종목을 빠르게 확인할 수 있도록 4 카드로 추렸습니다. 모든 카드는 **관찰 후보**이며 매매 권유가 아닙니다."
- **레이아웃**: `grid grid-cols-1 md:grid-cols-2` (모바일 1열 / 데스크톱 2x2)

### 4 카드 산출 기준 (요약)

| 카드 | 필터 | 정렬 | 표시 컬럼 | 안내 문구 |
|---|---|---|---|---|
| 🆕 **신규 진입 TOP10** | `change_type === "NEW"` | `today_rank` 오름차순 | 종목명·티커 / 오늘 순위 / 오늘 점수 / 섹터 배지 | "오늘 후보에 새로 들어온 종목입니다. 관찰 후보이며 매수 권유가 아닙니다." |
| 🚪 **이탈 TOP10** | `change_type === "DEPARTED"` | `previous_rank` (`yesterday_rank`) 오름차순 | 종목명·티커 / 직전 순위 / 직전 점수 / 섹터 배지 | "직전 스냅샷에는 있었지만 오늘 후보에서는 빠진 종목입니다." |
| ⬆ **순위 개선 TOP10** | `rank_delta` 가 number이고 `< 0` | `rank_delta` 오름차순 (예: -120, -80, -30) | 종목명·티커 / 오늘 / 직전 / 순위 △ / 점수 △ | "**가격 상승이 아니라 스캐너 내 후보 순위 개선입니다. 매수 권유가 아닙니다.**" |
| ⬇ **순위 하락 TOP10** | `rank_delta` 가 number이고 `> 0` | `rank_delta` 내림차순 (예: +120, +80, +30) | 종목명·티커 / 오늘 / 직전 / 순위 △ / 점수 △ | "**가격 하락이 아니라 스캐너 내 후보 순위가 밀린 것입니다. 매도 권유가 아니라 복기 보조 정보입니다.**" |

> **'상승/하락' 표현 안전장치 — 이중 보호:**
> 1. **카드 제목 자체**에 "순위"라는 단어를 박아넣어 ("순위 개선 TOP10" / "순위 하락 TOP10") 주가 등락 오해 가능성을 차단한다.
> 2. **카드 설명문**에도 매번 "가격 상승/하락이 아니라 스캐너 내 후보 순위 개선/하락"임을 명시한다.

### graceful 처리
- 해당 카드의 필터 결과가 0개 → "**해당 종목 없음**" 회색 텍스트 표시 (카드 자체는 항상 그려서 레이아웃 일관성 유지).
- `change_dump_latest.json` 부재 또는 `status !== "ok"` → v0.3-7 기존 안내 분기 그대로 (요약 카드 섹션 자체가 렌더되지 않음).
- 기존 상세 표·헤더·강조 박스·하단 안내는 그대로 유지.

### 종목 링크
모든 카드 row의 종목명은 v0.3-7 표와 동일하게 `<Link href="/stocks/${ticker}">` 유지.

- `status: not_enough_snapshots / parse_error / error` → 기존 v0.3-7 graceful 분기 그대로 (QuickTopCards 미렌더)
