# U-Turn Scanner — v0.7.3 핫픽스 보고서 (모달 → 인라인 펼침)

> **작성일:** 2026-06-13
> **선행:** `V0.7_2_REPORT.md`
> **문제:** v0.7.2 의 풀스크린 모달 방식이 모바일 브라우저에서 안정적으로 동작하지 않음. 버튼 탭 후 모달 미렌더 / 본문 미표시 / 복사 성공·실패 메시지 미노출. 사용자 화면에는 버튼만 남음.

## 1. 원인 추정

모바일 브라우저의 `position: fixed` + `inset-0` + `z-50` 모달은 다음 환경에서 비정상 동작 가능:
- in-app 브라우저 (카카오톡, 네이버앱, 인스타그램, 라인 등) — `fixed` overlay 가 in-app shell 뒤로 가려짐
- iOS Safari 일부 버전 — `inset-0` 가 viewport 와 어긋남 (URL 바 / 홈 인디케이터 영역 처리)
- 모바일 PWA / 홈 추가 후 standalone 모드 — 모달 z-index 가 status bar 와 충돌
- 외부 CSS 영향 — 부모 컨테이너의 `overflow: hidden` / `transform` 이 fixed 자식의 viewport 좌표를 깨뜨림

→ **모달 UX 자체를 포기하고 같은 화면 카드 안에서 인라인 펼침** 방식으로 전환. 사용자가 무엇이 일어났는지 한눈에 보이는 흐름.

## 2. v0.7.2 → v0.7.3 핵심 변화

| 항목 | v0.7.2 (모달) | v0.7.3 (인라인 펼침) |
|---|---|---|
| 렌더 위치 | `position: fixed inset-0 z-50` portal-like overlay | **부모 컨테이너 안 inline 흐름** (`<div className="w-full">`) |
| 컴포넌트 phase | `open: boolean` | **`'closed' \| 'generating' \| 'ready' \| 'error'`** 4 단계 명시 |
| 생성 중 안내 | 없음 (즉시 모달) | **"⏳ 리포트 생성 중..."** 화면 표시 |
| 오류 처리 | 없음 (try/catch 없음) | **try/catch + "⚠ 리포트 생성 실패" + 메시지 + [다시 시도] [닫기]** |
| 본문 위치 | 모달 안 (fixed) | **버튼 바로 아래** (inline) |
| 본문 표시 보장 | fixed 가 안 보이면 사라짐 | **inline 이라 무조건 보임** |
| 닫기 | 모달 외부 클릭 / 닫기 버튼 | **펼침 영역 안 [닫기] 버튼** + 컴포넌트 fragment 사라짐 |

## 3. 새 흐름 (4 phase state machine)

```
[closed]                                  ← 초기 상태
  └─ 버튼 [💬 GPT 상담용 리포트 보기/복사] 표시
     │
     │ 클릭
     ↓
[generating]                              ← try 진입
  └─ "⏳ 리포트 생성 중..." 표시
     │
     ├─ 성공 → [ready]
     └─ 실패 (catch) → [error]

[ready]                                   ← 펼침 영역
  └─ ┌────────────────────────────────┐
     │ GPT 상담용 리포트     [닫기]    │
     │ 아래 내용을 복사해서 ChatGPT 에  │
     │ 붙여넣으세요.                   │
     │                                  │
     │ [자동 복사 시도] [전체 선택]    │
     │ (성공/실패 메시지 박스)         │
     │                                  │
     │ ┌──────────────────────────┐  │
     │ │ # 오늘의 투자판단 리포트   │  │
     │ │ ... (마크다운 본문 inline) │  │
     │ │ 13~14px / userSelect: text│  │
     │ │ max-h-[60vh] overflow: auto│  │
     │ └──────────────────────────┘  │
     │ 💡 본문 길게 눌러 직접 복사    │
     └────────────────────────────────┘
     │
     │ [닫기]
     ↓
[closed]                                  ← 초기 상태로 복귀

[error]                                   ← try/catch 실패
  └─ ┌────────────────────────────────┐
     │ ⚠ 리포트 생성 실패              │
     │ {errorMsg}                       │
     │ [다시 시도] [닫기]              │
     └────────────────────────────────┘
```

## 4. 본문 영역 조건 (사용자 명세 §4)

```html
<pre
  ref={preRef}
  className="max-h-[60vh] overflow-y-auto rounded-md border border-slate-200 bg-slate-50 p-3
             font-mono text-[13px] leading-relaxed text-slate-800 sm:text-[14px]"
  style={{
    userSelect: 'text',
    WebkitUserSelect: 'text',
    cursor: 'text',
    whiteSpace: 'pre-wrap',
    wordBreak: 'break-word',
  }}
>
  {markdown}
</pre>
```

| 조건 | 적용 |
|---|---|
| `display: none` 금지 | ✓ (조건부 렌더로 phase === 'ready' 일 때만 마운트하지만 마운트되면 항상 visible) |
| `opacity: 0` 금지 | ✓ |
| `position: fixed` 금지 | ✓ (inline 흐름) |
| `user-select: text` | ✓ (style 속성 inline + Tailwind 호환) |
| `-webkit-user-select: text` | ✓ (`WebkitUserSelect: 'text'`) |
| `white-space: pre-wrap` | ✓ |
| `word-break: break-word` | ✓ |
| 모바일 폰트 13~14px | ✓ (`text-[13px] sm:text-[14px]`) |
| 최대 높이 + 내부 스크롤 | ✓ (`max-h-[60vh] overflow-y-auto`) |

## 5. 버튼 동작 (사용자 명세 §5 §6)

### 5-1. [전체 선택]
```ts
const range = document.createRange();
range.selectNodeContents(preRef.current);
const selection = window.getSelection();
selection.removeAllRanges();
selection.addRange(range);
preRef.current.scrollIntoView({ behavior: 'smooth' });

// userAgent 분기 안내
const isMobile = /Android|iPhone|iPad|iPod|Mobile/i.test(navigator.userAgent);
setSelectedHint(
  isMobile
    ? '✋ 텍스트가 선택되었습니다. 길게 눌러 복사를 선택하세요.'
    : '⌨ 텍스트가 선택되었습니다. Ctrl+C (Mac: ⌘+C) 로 복사하세요.'
);
```

### 5-2. [자동 복사 시도]
1. `navigator.clipboard.writeText` 시도
2. 실패 → `textarea + readonly + fixed 1×1 + selection range + execCommand('copy')` fallback
3. 둘 다 실패 → 노란 박스 안내 + 자동 [전체 선택] 호출
4. 실패해도 본문은 계속 화면에 보임 ✓

### 5-3. [닫기]
- `phase` 를 `'closed'` 로 변경 → 펼침 영역 사라짐 → 버튼만 다시 표시

## 6. 오류 처리 (사용자 명세 §7)

`handleOpen()` 안에서:
```ts
try {
  // 1. priceMap / prevMap 생성
  // 2. loadAllPlans()
  // 3. evaluateStrategyCondition / buildAll / buildConclusionText
  // 4. buildGptReport
  if (!md || md.trim().length === 0) {
    throw new Error('리포트 본문이 비어 있습니다.');
  }
  setMarkdown(md);
  setPhase('ready');
} catch (e) {
  setErrorMsg(e instanceof Error ? e.message : String(e));
  setPhase('error');
}
```

`error` phase 에서는 화면에:
```
⚠ 리포트 생성 실패
{errorMsg}
[다시 시도] [닫기]
```

→ 사용자가 "버튼 눌렀는데 아무 변화 없는" 상황 완전 차단.

## 13. 결론

v0.7.3 재핫픽스 완료. 모바일 GPT 리포트 표시 문제를 **모달 UX 자체 제거 + 인라인 펼침** 으로 해결. 컴포넌트가 4 phase state machine (`closed/generating/ready/error`) 으로 동작 — 사용자 클릭 후 항상 화면 변화 보임 (`⏳ 생성 중`, `⚠ 생성 실패`, 인라인 펼침 영역, 또는 [닫기] 후 버튼 복귀). 본문은 부모 컨테이너 안 inline 흐름에 배치 (`<div className="w-full">` wrapper) → `fixed` / `display:none` / `opacity:0` 사용 0건. 본문 `<pre>` 는 13~14px 가독성 + userSelect + whiteSpace pre-wrap + wordBreak + max-h-[60vh] overflow-y-auto. 펼침 영역 안 [자동 복사 시도] / [전체 선택] / [닫기] 3 버튼, 모든 상태 메시지 inline 색상 박스. `handleOpen` try/catch 로 빈 리포트 / 예외도 화면에 표시 — "버튼 눌러도 변화 없음" 케이스 완전 차단. 모달 미사용 이라 in-app 브라우저 / PWA standalone / iOS Safari 어떤 환경에서도 본문이 화면에 보이고 사용자가 직접 복사 가능. 투자 판단 / 시장 상태 / 전략 컨디션 / TradePlan / 자동매매 / Supabase write 모두 변경 0건. 호스트 PC 에서 `npm run build` 후 모바일 실 환경에서 동작 확인 부탁드립니다.
