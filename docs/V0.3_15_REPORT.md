> **작성 기준일:** 2026-06-05

> **채택안:** 영역 제목 **"오늘 다시 볼 후보"**, 5 카드 박스 바로 아래, 세로 1열 3 카드, 중복 회피, 후보 3 = U턴 시도 강화 (NEW는 v0.3-14와 중복이므로 제외)

## 1. 작업 목적

v0.3-14까지 홈 박스 5 카드는 "각 차원의 단일 최대값"(NEW/RANK_UP/RANK_DOWN/SCORE_UP/DEPARTED)을 보여줬다. 그러나 사용자는 여전히:
- "오늘 시간이 부족하면 어디**부터** 확인하지?"
- "여러 신호가 **동시에** 좋은 종목은?"
- "이미 상위권인데 더 강해진 종목은?"

같은 질문에 5 카드로 답할 수 없었다.

v0.3-15는 **"확인 우선순위 참고용"** 영역을 추가해 위 질문에 답한다. 매수 추천이 아니라 **다시 봐야 할 후보**를 우선순위로 제시.

## 4. `app/page.tsx` 변경 상세

### 4-1. `HomeSecondLookPicks` 타입 + `pickHomeSecondLook` 헬퍼 추가

`pickHomeKeyChanges` 직후에 신규 헬퍼:

```ts
interface HomeSecondLookPicks {
  topConsistent: ChangeRowLite | null;   // ① 강세 지속
  topMomentum: ChangeRowLite | null;     // ② 다방면 개선
  topUTurnStrong: ChangeRowLite | null;  // ③ U턴 시도 강화
}
```

### 4-2. 픽 로직 (중복 회피 포함)

```ts
// ① TOP10 유지 + 점수 상승 — score_delta 내림차순
const consistent = rows
  .filter(r => r.today_rank!=null && r.today_rank<=10 && r.score_delta!=null && r.score_delta>0)
  .sort((a,b) => b.score_delta - a.score_delta)[0] ?? null;

// 중복 회피용 used 집합
const used = new Set<string>();
if (consistent) used.add(consistent.ticker);

// ② 순위 상승 + 점수 상승 동시 (rank_delta 오름차순 + score_delta 보조)
const momentum = rows
  .filter(r => !used.has(r.ticker) && r.rank_delta!=null && r.rank_delta<0 && r.score_delta!=null && r.score_delta>0)
  .sort((a,b) => a.rank_delta - b.rank_delta || b.score_delta - a.score_delta)[0] ?? null;
if (momentum) used.add(momentum.ticker);

// ③ U턴 시도 단계 + 점수 상승 — score_delta 내림차순
const uturn = rows
  .filter(r => !used.has(r.ticker) && r.today_stage === 'U턴 시도' && r.score_delta!=null && r.score_delta>0)
  .sort((a,b) => b.score_delta - a.score_delta)[0] ?? null;
```
