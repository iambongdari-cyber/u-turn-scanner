# U-Turn Scanner — v0.7.4 핫픽스 보고서 (모바일 GPT 리포트 — 별도 페이지 + 일반 링크)

> **작성일:** 2026-06-13
> **선행:** `V0.7_3_REPORT.md`
> **문제:** v0.7.1~v0.7.3 까지 클립보드 fallback / 모달 / 인라인 펼침 모두 적용했지만 모바일 Chrome/기본 브라우저에서 [GPT 상담용 리포트 보기/복사] 버튼을 눌러도 반응이 없음. `onClick` 기반 동작이 모바일에서 안정적으로 작동하지 않는 환경 존재.
>
> **해결 방향:** JS 의존을 최소화 — onClick / 모달 / 인라인 펼침 모두 포기. **일반 링크 이동 + 별도 페이지** 로 전환. 브라우저의 기본 동작 (`<a href>` 이동) 은 어떤 환경에서도 동작.

## 1. 핵심 변화

| 항목 | v0.7.3 (인라인) | v0.7.4 (별도 페이지 + 링크) |
|---|---|---|
| 진입 방식 | `<button onClick={...}>` | **`<Link href="/beginner/gpt-report">`** |
| 모바일 onClick 의존 | 있음 | **없음** (브라우저 기본 링크 이동) |
| JS 비활성 환경 | 동작 불가 | **동작 가능** (SSR 본문이 항상 보임) |
| 리포트 본문 표시 | 같은 페이지 인라인 | **별도 페이지 풀스크린** |
| 라우팅 | client state phase | **Next.js 표준 라우팅** |
| 데이터 의존성 | 클라이언트 localStorage | **서버 SSR 우선** + 클라이언트 enhancement (보유/예약 종목 합성) |

핵심: **브라우저의 가장 기본적인 동작 (링크 이동) 을 사용** 하므로 onClick 이 실패하는 환경에서도 페이지 이동은 보장됨.

## 4. 데이터 흐름 (서버 SSR + 클라이언트 enhancement)

### 4-1. 서버 SSR (page.tsx)
```ts
const data = await loadBeginnerData(requestedDate);
const prevScan = await loadPreviousScanRows(requestedDate);

// plans = [] 가정 (서버는 localStorage 모름)
const { briefItems, selectedNewTargets } = buildAll({
  rows: data.rows,
  plans: [],
  priceMap,
  previousJudgementMap: prevMap,
  regimeMode: data.marketRegime?.mode,
});

initialMarkdown = buildGptReport({ ..., plans: [], briefItems, selectedNewTargets, marketRegime });
```

결과: **서버에서 생성된 markdown 이 HTML 안에 즉시 렌더** — JS 가 실패하거나 비활성이어도 본문이 보임.
- 시장 상태 / 오늘의 결론 / 해야 할 행동 / 하지 말 행동 / 매매계획 기록 대상 (서버 신규 후보 기준) / 참고 후보 — 모두 정상
- 보유종목 점검 / 예약매수 대기 → "없음" 으로 표시
- 전략 컨디션 → "데이터 부족" 으로 표시

### 4-2. 클라이언트 enhancement (GptReportClient.tsx)
```ts
useEffect(() => {
  const plans = loadAllPlans();
  if (plans.length === 0) { setEnhanced(true); return; }   // 서버 markdown 그대로

  const condition = evaluateStrategyCondition(plans);
  const { briefItems, selectedNewTargets } = buildAll({
    rows, plans, priceMap, previousJudgementMap, regimeMode, conditionState: condition.state,
  });
  // 1순위 종목명 동기화
  const syncedConclusion = buildConclusionText(regime.regime, regime.mode, selectedNewTargets[0]?.name ?? null);
  // markdown 재생성
  setMarkdown(buildGptReport({ ..., plans, briefItems, selectedNewTargets, marketRegime: { ..., conclusionText: syncedConclusion }}));
  setEnhanced(true);
}, []);
```

결과: mount 후 보유/예약 종목 + 전략 컨디션 실수치 반영된 markdown 으로 자동 업데이트. 사용자에게는 **"※ 현재 기기 저장 데이터 (보유/예약/컨디션) 반영됨"** 안내 노출.

### 4-3. JS 실패 환경 대응
- `<a href="/beginner/gpt-report">` 일반 링크 이동 → 브라우저 기본 동작 (어떤 환경에서도 동작)
- 페이지 진입 후 서버 SSR markdown 이 HTML 에 이미 렌더 → 본문 보임
- 클라이언트 enhancement 가 실패해도 서버 markdown 그대로 화면에 남음
- [전체 선택] 버튼만 동작 안 함 (수동 길게 눌러 복사로 우회 가능)
