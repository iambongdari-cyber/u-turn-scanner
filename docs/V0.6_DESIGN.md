## 1. 변경의 핵심 (v0.5 → v0.6)

| 영역 | v0.5 | v0.6 |
|---|---|---|
| 시장 상태 단계 | 3 (강세장/보합장/약세장) + 판단 보류 | **4 (강세장/보합장/약세장/위험구간)** + 판단 보류 |
| 전략 모드 | 3 (공격/선별/방어 + 짧은 반등) | **4 (공격/선별/방어/관망)** |
| 점수 매핑 | NEUTRAL 60~75 (감각적 보정) | **80~100 / 60~79 / 40~59 / 0~39 명시적 기준** |
| 리포트 최상단 | `## 0. 오늘 시장 상태` | **`## 0. 오늘의 결론`** (자연어 코치 톤) + `## 1. 시장 상태` 분리 |
| 전략 컨디션 | 없음 | **`## 2. 전략 컨디션`** 카드 신규 (v0.6 은 "데이터 부족" 표시) |
| 행동 지침 | 추천/금지 박스 (v0.5 후반 보강) | **`## 3. 오늘 해야 할 행동` + `## 4. 오늘 하지 말아야 할 행동`** 정식 섹션화 |
| 매매계획 기록 대상 | §2 매매계획 기록 대상 | **`## 5. 매매계획 기록 대상`** (행동 지침 아래로 배치) |

### 2-3. raw 점수 → displayScore 변환

기존 v0.5 의 7 시그널 합산 (-16 ~ +16) 을 0~100 으로 선형 변환:

```ts
// 핵심: 위 매핑이 사용자에게 직관적이도록 다소 압축
displayScore = Math.max(0, Math.min(100, Math.round(50 + score * 3.125)));

// 예시:
//   raw +16 → 100 (강세장)
//   raw  +8 →  75 (보합장 상단, 강세장 진입 직전)
//   raw  +3 →  59 → 사용자 명세대로 약세장 시작 — 따라서 보정 필요
```

**보정 필요:** 위 단순 선형 매핑으로는 호스트 데이터 (raw -2) 가 약세장으로 떨어집니다. v0.5 의 사용자 직관 ("지금은 보합장") 을 유지하려면:

```ts
// v0.6 채택: 보합장 폭 넓게 — raw 0 ± 5 → 60~79 보합장
function rawToDisplay(raw: number): number {
  // raw 점수를 비대칭 매핑:
  //  raw +9 이상  → 80~100 (강세장)
  //  raw -3 ~ +8  → 60~79  (보합장)
  //  raw -8 ~ -4  → 40~59  (약세장)
  //  raw -9 이하  →  0~39  (위험구간)
  if (raw >= 9) return Math.min(100, 80 + Math.round((raw - 9) * 2.86));
  if (raw >= -3) return Math.round(60 + (raw + 3) * (19 / 12)); // -3 → 60, +8 → 79
  if (raw >= -8) return Math.round(40 + (raw + 8) * (19 / 5));  // -8 → 40, -4 → 59
  return Math.max(0, Math.round(39 + (raw + 9) * (39 / 7)));   // -16 → 0, -9 → 39
}
```

**호스트 (2026-06-13) raw -2 → 약 62점 → 보합장 ✓** 사용자 직관과 일치.

### 5-2. v0.8 — 전략 컨디션 실계산
**StrategyConditionResult 채움 로직**:
- 최근 20회 CLOSED 매매만 집계 (`actualCount` 0~20)
- `actualCount < 5` → 여전히 DATA_INSUFFICIENT 표시
- 5 이상 → 등급 기준 적용:

| 등급 | 승률 |
|---|---|
| 매우 좋음 (EXCELLENT) | 70% 이상 |
| 좋음 (GOOD) | 60~70% |
| 보통 (AVERAGE) | 50~60% |
| 주의 (CAUTION) | 40~50% |
| 위험 (DANGER) | 40% 미만 |

- `expectedReturn = winRate × avgGain - (100-winRate) × avgLoss` (기대수익)
- "전략 상태가 주의/위험 이면 신규 진입 강도 자동 하향" — `selectTradePlanTargets` 가 컨디션도 받아 추가 감점 (모드 = 선별 + 컨디션 = 위험 → 더 엄격하게 0개)
