### 2-2. 분류 — 내부 5단계 → 사용자 표시 4단계 단순화

| 총점 | 내부 `MarketRegime` | 사용자 표시 (`RegimeDisplay`) | 전략 모드 (`RegimeMode`) |
|---|---|---|---|
| ≥ +9 | `STRONG_BULL` | **강세장** | **공격** (AGGRESSIVE) |
| +4 ~ +8 | `MILD_BULL` | **강세장** | **공격** (AGGRESSIVE) |
| -3 ~ +3 | `NEUTRAL` | **보합장** | **선별** (SELECTIVE) |
| -8 ~ -4 | `MILD_BEAR` | **약세장** | **방어 + 짧은 반등** (DEFENSIVE) |
| ≤ -9 | `STRONG_BEAR` | **약세장** | **방어 + 짧은 반등** (DEFENSIVE) |
| 시그널 < 2 | `UNKNOWN` | **판단 보류** | **선별** (SELECTIVE 가정) |

→ 사용자는 화면에서 **강세장 / 보합장 / 약세장 / 판단 보류** 4단계만 봅니다. STRONG_BULL/MILD_BULL 등 내부 enum 은 점수 산출 + 색상 톤 차별화에만 사용.

## 4. 장세별 종목 우선순위 반영 내용

### 4-1. `selectTradePlanTargets()` 모드별 가중치 분기

| Mode | 추가 점수 | 추가 감점 | 최대 캡 |
|---|---|---|---|
| **AGGRESSIVE** (공격) | 주도주 +10, 후발 강세 +5 | 이격 ≥ 12% : **-20** (추격매수 금지) | 보유/예약 없을 때 최대 3 (U턴 5/5 + 위험 LOW 가 2 개 이상 시) / 그 외 1 |
| **SELECTIVE** (선별) | 거래대금 회복 +10 | `ma60 == null` (손절가 근거 부족): **-50** (사실상 제외) | **최대 1개** (사용자 명세 §보합장 "1순위만") |
| **DEFENSIVE** (방어) | — | 모든 신규 후보: **-20** | **최대 1개** (보유/예약 우선) |

### 4-2. score < 0 종목은 자동 제외
모드별 감점으로 점수가 음수가 된 종목은 `.filter(s => s.score >= 0)` 로 제거. 결과적으로:
- 강세장에서 이격 ≥12% 추격 위험 종목 → 0순위에서 자동 제외
- 보합장에서 ma60 정보 없는 종목 → 자동 제외
- 약세장에서 약한 신규 후보 → 자동 제외 (보유/예약이 자연스럽게 화면 상단으로)

### 4-3. UNKNOWN 일 때 안전 동작
`regimeMode === undefined` 일 때 `selectTradePlanTargets` 안에서 `'SELECTIVE'` 로 기본 처리 → 보합장 가정으로 보수적 선별. 기존 v0.4-5 동작과 동일하게 1개 + 추가 페널티 없음 (단, ma60 정보 없는 종목은 약한 감점 → 호스트 데이터엔 영향 없음).

### 4-4. 화면 흐름 유지 (v0.4-5 그대로)
- 오늘 결론 / 매매계획 기록하기 / 1순위 가로형 카드 등 모든 UI 는 그대로
- 모드 영향은 **selectedNewTargets 의 점수/순위에만 적용** — 사용자는 자연스럽게 "오늘 강세장이라 주도주가 1순위로 올라옴", "오늘 보합장이라 1순위만 보임" 등으로 인식
