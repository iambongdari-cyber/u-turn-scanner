# U턴스캐너 매매 운영 원칙서

> 슈퍼개미 관점 — 살아남는 사용자가 되기 위한 운영 매뉴얼
> 버전 기준: v0.7.6.3
> 마지막 갱신: 2026-06-13

---

## 0. 이 문서의 위치

`USER_GUIDE.md` 가 "화면을 어떻게 쓰는가" 라면, 이 문서는 **"실제 시장에서 어떻게 행동할 것인가"** 를 정리한 운영 매뉴얼입니다.

핵심 한 줄:
> **수익을 내는 것보다 살아남는 것이 먼저.**

U턴스캐너는 자동매매가 아닙니다. 실제 키움 주문은 사용자가 직접 입력합니다. 이 원칙서는 그 입력 직전에 사용자가 스스로 점검할 수 있는 체크리스트입니다.

---

## 1. 절대 원칙 7가지 — 매번 입력 전 확인

다음 7 가지가 무너지면 매매 자체를 보류합니다.

### 원칙 1 — 손절가 없는 매수 금지
손절 기준가가 명확하지 않으면 매매계획 기록조차 시작하지 않습니다. 키움 예약매수 직전에 손절 가격을 다시 확인합니다. 손절가 = "여기까지 떨어지면 나는 틀린 것" 의 가격입니다.

### 원칙 2 — 1순위 외 종목 매수 금지
오늘의 결론이 안내한 1순위 종목 외에는 신경 쓰지 않습니다. "이 종목도 좋아 보여서" 라는 이유로 동시에 여러 종목을 사지 않습니다.

### 원칙 3 — 시장 상태가 위험구간이면 신규 진입 금지
점수 0~39 위험구간 = 전략 모드 "관망". 신규 매수 보류, 현금 보유 최우선. 화면이 1순위를 0 개로 표시하면 그대로 따릅니다.

### 원칙 4 — 전략 컨디션이 위험이면 신규 진입 금지
승률 40% 미만 = 컨디션 "위험". 시장 모드와 무관하게 신규 0 개. 자기 전략이 작동 안 하는 구간에서 추가 손실을 막습니다.

### 원칙 5 — 추격매수 금지
이격(현재가가 60일선 대비) +12% 이상 종목은 추격 위험. 강세장이라도 자동으로 점수 -20 감점되어 1순위에서 제외됩니다. 화면이 "이격 +N%" 경고하면 따릅니다.

### 원칙 6 — 손절 미루기 금지
손절 기준가 이탈 시점에 즉시 매도. "조금만 더 보자" 가 가장 큰 손실의 시작입니다. 손절가는 기록한 순간부터 사용자와의 약속입니다.

### 원칙 7 — 매매 결과 반드시 기록
매도완료 시 실제 종료가 + 종료일 입력. 손실 매매도 반드시 기록 — 전략 컨디션이 정확해야 다음 매매가 정확해집니다.

## 2. 시장 상태별 행동 원칙

### 2-1. 강세장 (80~100점, 전략 모드 = 공격)

**상황 해석**
- KOSPI/KOSDAQ 60일선 위 + 20일 수익률 양호 + 강한 섹터 우세
- 돈이 시장 전체에 들어오는 시기
- 주도주 추세 추종이 가능

**행동 원칙**
- 신규 매매계획 최대 3 개 (단, 보유/예약 있으면 1 개)
- 주도주 / 후발 강세 후보 우선
- **눌림 / 재돌파 가격이 명확한 종목만 진입**
- 손절가 -5% 이내 명확하게 설정
- 현금 비중 일부 축소 가능

**금지 행동**
- 계획 없는 추격매수 (이격 12% 이상)
- 손절가 없는 진입
- 한 번에 풀매수 (분할 진입 원칙)

**주의**
- 강세장 후반은 추격 위험 종목이 늘어남
- 화면의 추격 위험 경고를 신뢰
- 강세장이라고 무조건 매수가 아닙니다

### 2-2. 보합장 (60~79점, 전략 모드 = 선별)

**상황 해석**
- 일부 섹터만 움직이는 상태
- 시장 방향성 애매
- 강한 종목만 살아남음

**행동 원칙**
- 신규 매매계획 **1 개만**
- 거래대금 회복 + 60일선 회복 + 손절가 명확한 종목만
- 예약매수 최대 1 건
- 현금 비중 50% 이상 유지
- 애매하면 관망 우선

**금지 행동**
- 후보 전체 훑기 (화면이 절제하라고 안내함)
- 신규 예약매수 여러 개 동시 진행
- 테마주 추격
- 손절가 없는 매수

**주의**
- 보합장은 인내의 영역
- "오늘은 1 개만 본다" 가 핵심
- 화면이 NAVER 1 개만 검토하라고 하면 그대로 따릅니다

### 2-3. 약세장 (40~59점, 전략 모드 = 방어)

**상황 해석**
- 시장 전체에서 돈이 빠지는 분위기
- 60일선 이탈 또는 20일 수익률 마이너스
- 신규보다 방어 우선

**행동 원칙**
- 신규 진입 최소화 (캡 1 개)
- 보유종목 점검 우선 (손절가 / 추가매수 조건)
- 예약매수 대기 종목 재검토 (취소 또는 가격 재산정)
- 신규 후보는 **손절가가 가까운 종목만 작게**
- 현금 비중 확대

**금지 행동**
- 물타기 (떨어진다고 평균단가 낮추기)
- 반등 기대 매수 (V 자 반등 노림)
- 손실 종목 방치
- 무리한 신규진입

**주의**
- 약세장은 손실을 줄이는 게 수익
- 보유종목의 손절가를 다시 점검
- 화면이 보유 점검 우선이라고 안내하면 따릅니다

### 2-4. 위험구간 (0~39점, 전략 모드 = 관망)

**상황 해석**
- 시장 전체 신호 마이너스
- 60일선 이탈 + 20일 수익률 큰 폭 마이너스 + 약한 섹터 우세
- 추세 자체가 깨진 구간

**행동 원칙**
- **신규 진입 금지** (화면이 자동으로 1순위 0 개로 표시)
- 보유종목 위험 점검 — 손절가 이탈한 종목 즉시 매도
- 현금 최우선
- 매매보다 관망 우선

**금지 행동**
- 신규 매수 (어떤 이유에서도)
- 레버리지성 매매 (신용/미수)
- 손절 회피 ("좀 더 기다리면")
- 감정적 복수매매 (손실 회복 시도)

**주의**
- 위험구간에서 잘 쉬는 것이 다음 강세장에서 가장 큰 수익
- 이 구간에서 평정심 유지가 핵심
- 화면이 0 개라고 표시하면 진짜로 0 개입니다

## 3. 전략 컨디션별 진입 강도 조절

매도완료 결과가 5건 이상 누적되면 전략 컨디션이 계산됩니다. 이 컨디션에 따라 신규 진입 강도를 조절합니다.

### 3-1. 매우 좋음 (승률 70%+)

**해석**
- 내 전략이 매우 잘 작동 중
- 현재 시장 / 종목 선정 / 손절 운영 모두 잘 맞음

**행동 원칙**
- 현재 모드 유지
- 강세장에서 보유/예약 있어도 신규 2 개까지 허용 (캡 확대)
- 손절 원칙 그대로 유지
- 자만 금지 — 컨디션은 변동성 큼

**주의**
- 매우 좋음이라고 베팅 크기를 무리하게 키우지 않음
- 1 종목 비중을 갑자기 크게 바꾸지 않음

### 3-2. 좋음 (60~69%)

**해석**
- 잘 작동 중
- 현재 운영 그대로 진행

**행동 원칙**
- 시장 모드 추천대로 진행
- 추가 변화 없음
- 손절 원칙 유지

### 3-3. 보통 (50~59%)

**해석**
- 평균 수준 — 50% 가 가까스로 넘는 상태
- 손실폭이 커지고 있을 가능성

**행동 원칙**
- 손절 원칙을 더 엄격하게
- **평균손실 폭을 줄이는 게 우선**
- 신규 진입 1 개로 캡 축소 (강세장도 2 개까지만)
- 손익비 좋은 종목만 선별

### 3-4. 주의 (40~49%)

**해석**
- 컨디션 흔들리는 중
- 승률 또는 기대수익이 마이너스 방향

**행동 원칙**
- 신규 진입 강도 하향 (점수 -15 자동 감점)
- 보유종목 점검 우선
- 손절가 더 보수적으로 (60일선 +근접)
- 약세장 + 주의 컨디션 = 신규 0 개

### 3-5. 위험 (40% 미만)

**해석**
- 전략이 작동 안 하는 구간
- 최근 매매 패턴이 시장과 어긋남

**행동 원칙**
- **신규 진입 보류** (화면이 자동으로 0 개로 표시)
- 최근 손실 종목 패턴 회고 필수
- 손실 매매들의 공통점 분석:
  - 손절을 미뤘는지?
  - 추격매수였는지?
  - 시장 상태에 안 맞는 종목이었는지?
- 현금 보유 + 컨디션 회복 대기

**주의**
- 위험 컨디션에서 추가 진입은 손실 확대로 직결
- 화면이 0 개라고 하면 진짜 0 개

## 4. 컨디션 신뢰도별 운영 원칙

### 신뢰도 "계산 안 함" (0~4건)

**상황**
- 매도완료 결과 미충분
- 컨디션 수치 표시 안 됨

**원칙**
- 시장 모드 추천대로만 진행
- 보합장 가정으로 보수적 접근
- 단일 종목 비중 작게
- 매도완료 결과 5건 누적이 목표

### 신뢰도 "낮음" (5~9건)

**상황**
- 컨디션 1차 계산됨
- 표본이 적어 변동성 큼

**원칙**
- 컨디션 수치를 그대로 믿지 말고 시장 모드 우선
- 신규 캡 1 개로 보수적 유지
- 표본 누적이 우선 — 무리한 베팅 X

### 신뢰도 "보통" (10~19건)

**상황**
- 컨디션 수치 신뢰 가능 시작
- 패턴 인식 가능 시점

**원칙**
- 컨디션 등급에 맞춰 캡 조절
- 시장 모드 + 컨디션 매트릭스 적용
- 매매 결과를 보면서 캡을 미세 조정

### 신뢰도 "높음" (20+건)

**상황**
- 컨디션 수치 충분히 신뢰 가능
- 매매 패턴 안정화

**원칙**
- 컨디션 등급을 그대로 운영 기준으로
- 등급 변동(매우 좋음 → 좋음 등) 시 즉시 캡 재조정
- 한 달 단위로 매매 회고

## 5. 매매 결과 기록 원칙

전략 컨디션이 정확하려면 매도완료 결과가 정확해야 합니다.

### 5-1. 매도완료 시 반드시 기록
- 매도완료 = CLOSED 상태로 전환할 때
- 실제 종료가 + 종료일 + 메모(선택)
- 부분 매도 평균가는 사용자가 직접 수익률 수정

### 5-2. 손실 매매도 반드시 기록
- 손실이라고 기록 안 하면 승률이 부정확
- 손실 패턴 회고에 가장 중요한 데이터
- "이건 잊고 싶다" 가 가장 위험한 회피

### 5-3. 결과 미입력은 자동 제외
- 매도완료 했지만 결과 미입력 = 전략 컨디션 집계 제외
- 화면에 "※ 결과 미입력 N건" 안내가 뜸
- 결과 미입력이 많으면 컨디션 수치를 신뢰할 수 없음

### 5-4. 변경 이력 활용
- 목표가/손절가 변경 시 사유 필수 입력
- 변경 이력이 카드 안에 누적됨
- 사후 회고에 중요한 정보

## 6. 감정 매매 금지 규칙

### 6-1. 충동 매수 금지
- 화면이 1순위로 안내 안 한 종목 → 매수 X
- "지금 이 종목이 좋아 보여서" → 매수 X
- 매매계획 기록 모달의 손절가 미입력 → 매수 X

### 6-2. 복수매매 금지
- 손실 직후 다른 종목으로 손실 회복 시도 → X
- 위험 컨디션에서 추가 진입 → X
- "다음 종목으로 한 방에" → X

### 6-3. 자기과신 금지
- 매우 좋음 컨디션이라고 베팅 크기 갑자기 키우기 → X
- 강세장이라고 풀매수 → X
- 손절가 무시한 보유 → X

### 6-4. 패닉 매도 금지
- 시장이 갑자기 빠진다고 손절가 안 닿은 종목 무차별 매도 → X
- 손절가는 지키되, 손절가 안 닿은 종목까지 던지지 않음
- "남들 다 던지니까" 가 가장 위험

### 6-5. SNS / 커뮤니티 따라가지 않기
- 화면의 1순위는 데이터 기반
- 커뮤니티의 종목은 감정 기반 가능성
- U턴스캐너 안내와 커뮤니티 종목이 다르면 화면을 따름

## 7. 일일 운영 루틴 (실전 체크리스트)

### 7-1. 장 시작 전 (또는 출근 전)
- [ ] `/beginner` 진입
- [ ] 오늘의 결론 확인 — 시장 상태 / 1순위 종목
- [ ] 시장 상태 점수 확인 (위험구간이면 신규 보류)
- [ ] 전략 컨디션 등급 확인 (위험이면 신규 보류)
- [ ] 1순위 종목이 있고 + 시장이 신규 진입 가능한 상태라면:
  - [ ] 매매계획 기록 모달 열고 손절가 명확하게 설정
  - [ ] 키움 HTS/MTS 에서 예약매수 직접 입력

### 7-2. 장중
- [ ] 예약매수 체결 알림 확인 (키움)
- [ ] 체결되면 `/beginner` 와서 [1차 체결] / [2차 체결] 클릭 + 실제 체결가 입력

### 7-3. 장 마감 후 (또는 퇴근 후 10분)
- [ ] `/beginner` 진입
- [ ] 보유종목 점검 — 손절가 이탈 / 목표가 근접 / 추가매수 조건 확인
- [ ] 매도한 종목이 있으면 [매도완료] + 결과 입력
- [ ] 전략 컨디션 누적 확인
- [ ] 필요하면 GPT 상담용 리포트 복사 → ChatGPT 추가 상담

### 7-4. 주말 (회고)
- [ ] 지난 투자판단 달력 확인 — 미확인 날짜 회고
- [ ] 최근 매도완료 결과 회고 — 손실 매매의 공통점 점검
- [ ] 전략 컨디션 등급 변화 확인
- [ ] 다음 주 진입 강도 결정

## 8. 위기 대응 매뉴얼

### 8-1. 위험구간 + 위험 컨디션 동시 발생
- 신규 진입 금지 (양쪽 모두 0 개 강제)
- 보유종목 손절가 이탈 점검
- 현금 비중 최대 확보
- 매매 일시 중단 검토

### 8-2. 시장 급락 (사이드카 market_flow = "약세 흐름" + KOSPI/KOSDAQ 동시 -5% 이상)
- 보유종목 손절가 우선 확인
- 손절가 이탈은 즉시 매도
- 신규 진입 보류
- "지금이 기회" 라는 감정 차단

### 8-3. 보유종목 손실 누적 (3 종목 이상 손절)
- 패턴 회고 — 추격매수였는지? 시장 상태 무시했는지?
- 전략 컨디션 등급 재확인
- 등급이 주의/위험으로 떨어졌다면 신규 진입 보류
- 매매 일시 중단 + 컨디션 회복 대기

### 8-4. 큰 수익 직후 자만 위험
- "이대로 가면 다음 종목도" 라는 감정 차단
- 매도완료 결과 정확하게 기록 (자랑 X, 회고 O)
- 컨디션 등급이 매우 좋음이라도 캡 무리하게 늘리지 않음
- 다음 매매도 동일한 손절 원칙 유지

## 11. 매매 전 최종 5문장 체크

키움 예약매수를 입력하기 전, 아래 5개를 **소리 내어** 확인합니다.

1. 오늘 시장 상태는 신규 진입 가능한 구간인가?
2. 전략 컨디션이 위험은 아닌가?
3. 이 종목이 오늘의 1순위인가?
4. 손절가를 숫자로 정했는가?
5. 이 주문은 키움에 내가 직접 입력하는 실제 주문임을 알고 있는가?

하나라도 "아니오"라면 매매를 보류합니다.

### 왜 5문장인가
- 실제 돈이 들어가기 **직전의 마지막 브레이크**
- 화면에 안 보이는 사용자 본인의 점검
- 운영 원칙(§1~§10)을 한 페이지로 압축
- 1·2·3 = 시장/컨디션/종목 — 환경 점검
- 4 = 손절가 — 위험 통제
- 5 = 주문 책임 — 사용자 본인 확인

### 매일 출근 전 또는 매매 시점에
- 모니터 옆에 출력해서 붙여두기
- 한 번이라도 "아니오" 나오면 그 종목은 보류
- 자기와의 약속
