## 3. 가상 매수 시 저장할 스냅샷 (사용자 명세 10필드 + 채점용)

### 3-1. 저장 인터페이스 (1차 보완 + 본 3차 보완 통합)

```ts
// app/_lib/virtual_trade.ts (1차 보완에서 신규, 본 보완에서 확장)

type ScoreVerdict = 'SUCCESS' | 'FAILURE' | 'IN_PROGRESS';

interface ScoringSnapshot {
  // 사용자 명세 10필드 (당시 AI 판단 스냅샷)
  name: string;
  ticker: string;
  bought_at: string;                          // ISO YYYY-MM-DD (KST)
  buy_price: number;                          // 가상 매수가 (저장 시점 close 권장)
  category_at_time: BeginnerCategory;         // BOTTOM_UTURN | LEADER | FOLLOWER
  action_recommend_at_time: ActionRecommend;  // WATCH | BUY_SPLIT | HOLD | ...
  risk_at_time: RiskLevel;                    // LOW | MEDIUM | HIGH
  uturn_conditions_at_time: UTurnConditions | null;  // 바닥 U턴 후보만 (5/5 / 4/5 등)
  why_picked_at_time: string[];               // 자연어 2~3 문장
  beginner_checklist_at_time: string[];       // 당시 행동 가이드 체크리스트
}

interface VirtualBuyRecord {
  id: string;                                 // UUID
  scoring_snapshot: ScoringSnapshot;          // 위 10필드
  quantity?: number;                          // 선택 (몰빵 금지 안내용)
  user_note?: string | null;                  // 사용자 메모 (선택)

  // 채점 결과 (자동 채점 시 채워짐)
  // - v0.4: current 만 사용 (현재 수익률 단순 표시)
  // - v0.5+: d1, d3, d7, d30 누적 채점
  evaluations: {
    current?: {
      checked_at: string;       // ISO 시각
      current_price: number;
      pnl_pct: number;
      verdict: ScoreVerdict;
    };
    d1?: { checked_at: string; price: number; pnl_pct: number; verdict: ScoreVerdict };
    d3?: { ... };
    d7?: { ... };
    d30?: { ... };
  };
}
```

## 4. 자동 채점 기준 설계 (v0.5+ 본격, v0.4 부분 채택)

### 4-1. 판정 기준 (사용자 명세 그대로)
```ts
function scoreVerdict(pnl_pct: number): ScoreVerdict {
  if (pnl_pct >= 5) return 'SUCCESS';
  if (pnl_pct <= -5) return 'FAILURE';
  return 'IN_PROGRESS';
}
```

| 수익률 | 판정 | 표시 |
|---|---|---|
| **≥ +5%** | SUCCESS | 🟢 성공 |
| **≤ -5%** | FAILURE | 🔴 실패 |
| **그 사이** | IN_PROGRESS | 🔵 진행중 |

### 4-2. 채점 기간 (4 단계)
| 기간 | 의미 | v0.4 | v0.4.1 | v0.5+ |

| **D+1** | 매수 다음 거래일 | ✗ | ✗ | ✅ daily snapshot 활용 |
| **D+3** | 매수 후 3 거래일 | ✗ | ✗ | ✅ |
| **D+7** | 매수 후 7 거래일 | ✗ | ✗ | ✅ |

### 5-3. 헬퍼 함수 시그니처

```ts
// app/_lib/scoring.ts (신규)
function evaluateCurrentPnl(
  record: VirtualBuyRecord,
  currentPriceLookup: Map<string, number>,  // ticker → close
): {
  current_price: number;
  pnl_pct: number;
  verdict: ScoreVerdict;
} | null {
  const price = currentPriceLookup.get(record.scoring_snapshot.ticker);
  if (price == null || price <= 0) return null;
  const buy = record.scoring_snapshot.buy_price;
  if (buy <= 0) return null;
  const pnl = (price - buy) / buy * 100;
  return {
    current_price: price,
    pnl_pct: pnl,
    verdict: scoreVerdict(pnl),
  };
}
```
