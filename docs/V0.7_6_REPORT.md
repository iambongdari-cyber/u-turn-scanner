> **작성일:** 2026-06-13
> **선행:** `V0.7_5_REPORT.md`
> **문제:** v0.6 에서 추가된 "오늘 해야 할 행동" / "오늘 하지 말아야 할 행동" 두 박스가 현재 화면에서는 §0 오늘의 결론 + §1 시장 상태 박스의 advice/메시지와 내용이 중복. 매매계획 기록하기까지 스크롤이 길어지고, 1순위 종목 카드가 화면 아래로 밀림.

- **데이터는 보존** — `buildRecommendedActions()` / `buildForbiddenActions()` 함수, `MarketRegimeResult.recommendedActions/forbiddenActions` 필드, GPT 리포트 §3 §4 모두 그대로
- `MarketRegimeBox` 의 **자세히 보기** 영역에 보조 표시 추가 — 필요한 사용자만 펼쳐서 확인

## 2. 화면 순서 변경

### 2-1. 변경 전 (v0.7.5)
```
1. 오늘의 결론                ← 핵심 자연어
2. 시장 상태                  ← 점수 + advice
3. 전략 컨디션
4. 오늘 해야 할 행동          ← 중복 ⚠
5. 오늘 하지 말아야 할 행동   ← 중복 ⚠
6. 매매계획 기록하기          ← 1순위 종목 카드 (화면 아래로 밀림)
7. 보유 + 예약
8. 관심 / 참고 (접힘)
9. 지난 투자판단 (달력)
10. GPT 상담
```

### 2-2. 변경 후 (v0.7.6)
```
1. 오늘의 결론
2. 시장 상태                  ← "자세히 보기" 안에 추천/금지 행동 보조 표시
3. 전략 컨디션
4. 매매계획 기록하기          ← 한 영역 줄어들어 1순위 종목이 더 위로
5. 보유 + 예약
6. 관심 / 참고 (접힘)
7. 지난 투자판단 (달력)
8. GPT 상담
```

→ 영역 10 → 8 로 압축. 사용자가 오늘의 결론을 본 직후 1순위 매매계획 기록으로 자연스럽게 이동.

## 8. 테스트 시나리오

### 8-1. 정상 흐름
1. `/beginner` 진입
2. 화면 위에서 아래로: ① 오늘의 결론 → ② 시장 상태 → ③ 전략 컨디션 → ④ 매매계획 기록하기
