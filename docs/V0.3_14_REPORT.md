## 1. 작업 목적

v0.3-12/13까지 홈 박스 4 카드(NEW/RANK_UP/RANK_DOWN/SCORE_UP)는 완성됐지만 사용자 명세 4 focus 키 중 `out`(이탈)이 홈에서 트리거 없이 URL 직접 입력으로만 접근 가능했다. v0.3-14는 **DEPARTED 1 카드 추가**로 사용자 명세를 홈에서 정확히 5종 변화 한눈에 인지 가능하게 한다.

설계 §3에서 옵션 A(`yesterday_rank` 오름차순)을 추천한 이유:
- **임팩트 강**: 직전 12위였던 강한 종목이 빠진 사건은 사용자 직관에 즉시 들어옴
- **의미 자연**: NEW = "오늘 들어옴 → today_score"  /  DEPARTED = "직전에서 빠짐 → yesterday_rank" — 시점 정보 축이 자연

## 3. `app/page.tsx` 변경 상세

### 3-1. `ChangeRowLite` 인터페이스에 `yesterday_stage` 추가
DEPARTED row 는 `today_stage = null`(오늘 후보권 빠짐) → 카드에 직전단계 표시를 위해 `yesterday_stage` 필요.

```ts
interface ChangeRowLite {
  ...
  today_stage: string | null;        // v0.3-10
  yesterday_stage: string | null;    // v0.3-14 신규
  ...
}
```

### 3-2. `HomeKeyPicks` 에 `topDeparted` 추가

```ts
interface HomeKeyPicks {
  topNew: ChangeRowLite | null;
  topRankUp: ChangeRowLite | null;
  topRankDown: ChangeRowLite | null;
  topScoreUp: ChangeRowLite | null;
  topDeparted: ChangeRowLite | null;  // v0.3-14
}
```

### 3-3. `pickHomeKeyChanges` 에 옵션 A 픽 로직

```ts
const departedPick = [...rows]
  .filter((r) => r.change_type === 'DEPARTED' && typeof r.yesterday_rank === 'number')
  .sort((a, b) => (a.yesterday_rank as number) - (b.yesterday_rank as number))[0]
  ?? null;
```
- 필터: `change_type === 'DEPARTED'` AND `yesterday_rank` 가 number
- 정렬: `yesterday_rank` 오름차순 (=직전 가장 높은 순위)
- 첫 항목 픽 (없으면 null)

### 3-4. `MiniHighlight` 시그니처에 `slate` tone 추가

```ts
tone: 'emerald' | 'sky' | 'amber' | 'indigo' | 'slate';  // v0.3-14
...
tone === 'slate' ? 'border-slate-300 bg-slate-50 text-slate-800' : ...
```
QuickCard 이탈 TOP10 (v0.3-8)과 일관된 회색 톤.

### 3-5. `MiniHighlight` 본문에 stage 자동 분기

기존 v0.3-10 코드는 `row.today_stage` 만 보고 "현재단계" 표시. DEPARTED 는 `today_stage = null` 이므로 분기 추가:

```tsx
{(row.today_stage || row.yesterday_stage) && (
  <div className="mt-0.5 text-[11px] text-slate-600">
    <span className="text-slate-500">{row.today_stage ? '현재단계' : '직전단계'}</span>{' '}
    <span className="font-medium text-slate-800">{row.today_stage ?? row.yesterday_stage}</span>
  </div>
)}
```

- `today_stage` 있음 → 라벨 "현재단계", 값 `today_stage` (NEW/RANK_UP/RANK_DOWN/SCORE_UP 동작 동일)
- `today_stage` 없고 `yesterday_stage` 있음 → 라벨 "직전단계", 값 `yesterday_stage` (DEPARTED 동작)
- 둘 다 없음 → 라인 미렌더 (graceful)

### 3-6. `ChangeHighlightBox` grid 클래스 변경 (설계 방안 A)

```diff
- <div className="grid grid-cols-1 gap-2 sm:grid-cols-2 lg:grid-cols-4">
+ <div className="grid grid-cols-1 gap-2 sm:grid-cols-2 lg:grid-cols-5">
```

| breakpoint | 배치 |
|---|---|
| 모바일 | 5 행 세로 1 열 |
| sm (640+) | 2 열 → 3 행 (마지막 단독) |
| lg (1024+) | **1 행 5 열** |

### 3-7. 5번째 `MiniHighlight` (대표 이탈) 추가

```tsx
<MiniHighlight
  label="대표 이탈"
  icon="🚪"
  tone="slate"
  row={picks.topDeparted}
  metric={
    picks.topDeparted?.yesterday_rank != null
      ? `직전 순위 ${fmtRankSimple(picks.topDeparted.yesterday_rank)}${
          picks.topDeparted?.yesterday_score != null
            ? ` · 직전 점수 ${fmtScoreSimple(picks.topDeparted.yesterday_score)}`
            : ''
        }`
      : ''
  }
  reason="직전 스냅샷에서 가장 높은 순위였던 종목"
  detailHref="/changes?focus=out"
/>
```

위치: 기존 4 카드(NEW → RANK_UP → RANK_DOWN → SCORE_UP) 다음, 같은 grid 내 5번째 슬롯.
