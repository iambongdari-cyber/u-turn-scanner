## 1. 작업 목적

v0.3-7~v0.3-9에서 `/changes` 화면은:
- 최상단 4 핵심 highlight 카드 (v0.3-9)
- 요약 6칸 (v0.3-7)
- TOP10 4 카드 (v0.3-8)
- 상세 표 (v0.3-7)

이 모든 정보가 모이며 충분히 풍부해졌다. 그러나 사용자는 홈에 진입했을 때 여전히:
- 홈 → "오늘 변화 있나?" 확인 → `/changes` 클릭 → 핵심 카드 확인

이라는 두 번의 화면 이동이 필요했다. v0.3-10은 **홈 자체에서 핵심 4종목을 즉시 보여주고**, 자세한 내용은 `/changes`로 한 번에 점프할 수 있게 한다.

박스는 의도적으로 **작고 컴팩트**하게 — 홈의 기존 영역(SidecarFreshnessBox / HomeSummaryCard / SearchForm)을 가리지 않는다.

| 3 | ⬇ **최대 순위하락** | `rank_delta` 가 number이고 `> 0` | `rank_delta` 내림차순 | 종목명·티커 / **직전 → 현재 · ▼+N** / **현재단계 \<단계명\>** |

> **현재단계 표시 정책**: 4 카드 모두에서 `row.today_stage` 가 truthy일 때만 "현재단계 \<단계명\>" 라인을 표시(예: `현재단계 바닥 관찰`). null/빈문자열이면 라인 자체 미렌더 — 레이아웃 깨지지 않음. 표시 가능한 단계명은 `바닥 관찰` / `U턴 시도` / `U턴 확인` / `추세전환 후보` 등 사이드카가 제공하는 기존 라벨.

### 카드 1 fallback
NEW 종목 중 `today_score`가 모두 null인 경우라도 박스가 비어 보이지 않도록 `today_rank` 오름차순으로 대체 픽한다.

"직전 스냅샷 대비 핵심 종목 4건만 추린 보조 표시입니다. **'상승/하락'은 가격이 아니라 스캐너 내 후보 순위·점수의 변화**입니다. 매매 권유가 아닙니다."

## 6. graceful 처리

| 시나리오 | 동작 |
|---|---|
| `change_dump_latest.json` 부재 | 박스에 "어제 대비 변화 데이터가 아직 없습니다. `scripts/compare_snapshots.py` 실행 후 다시 확인하세요." 안내 + 우상단 `/changes` 이동 버튼 유지 |
| JSON 파싱 실패 (try/catch에서 null 반환) | 위와 동일 분기 |
| `status !== "ok"` (e.g. `not_enough_snapshots`) | 위와 동일 분기 — 안내 + 버튼 유지 |
| 4 픽 모두 null (예: 변화 0건) | 박스는 정상 톤 유지, 내부에 "오늘 두드러진 변화가 없습니다." 단일 안내 + 버튼 유지 |
| 일부 픽만 null (예: SCORE_UP 카드만 0건) | 해당 카드만 "해당 없음" 표시, 나머지는 정상 종목 표시 |
| 위 어느 경우든 `/changes` 이동 버튼은 항상 노출 | 사용자가 자세한 안내를 받을 수 있도록 일관성 보장 |

모든 분기에서 throw 0건. **기존 홈 화면 기능 (SidecarFreshnessBox / HomeSummaryCard / SearchForm / FlowSection 5종)은 모두 그대로 유지**.

- `loadChangeDumpForHome` 내부 try/catch로 `null` 안전 반환
