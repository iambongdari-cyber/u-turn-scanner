## 4. 새 화면별 기능 요약

### 🗺 `/market` — 오늘의 시장 지도
- `market_indices`에서 KOSPI/KOSDAQ 최근 60일 종가 읽어 **60일선 추정**, 최신 종가, 전일 대비 표시
- 두 지수의 60일선 위/아래 판정으로 **강세 흐름 / 중립 흐름 / 약세 흐름** 한 줄 요약 표시
- `reports`에서 가장 최근 일일·주간 리포트로 바로가기, `/history`·`/opportunities` 링크
- 화면 하단에 "관찰·보조 표시이며 매매 권유가 아님" 명시

### 🎯 `/opportunities` — 오늘의 기회 포착판
- 최신 일일 `reports` + 해당 `scan_results` 전체 읽음
- `final_grade` → 표현 변환
  - **A / B → 기회 후보**
  - **CHASE_RISK → 추격 위험**
  - **WATCH / EXCLUDE → 조건 부족**
- 각 종목에 `golden_days_ago` 기반 **단계 라벨** 함께 표시
  - 없음 → 바닥 관찰
  - 0~1일 → U턴 시도
  - 2~5일 → U턴 확인
  - 6일+ → 추세전환 후보
- 클릭 시 기존 `/stocks/[ticker]` 화면으로 이동
- 화면 하단에 "보조 분류이며 매매 권유가 아님" 명시

### 📋 `/kiwoom-helper` — 키움 자동감시 참고표
- **상단 노란 안내 박스**(요청 문구 그대로):
  > "이 화면은 키움 자동감시주문에 직접 입력하기 전 **참고용으로 정리한 표**입니다. **자동주문 기능이 아니며**, 최종 입력과 주문 여부는 사용자가 키움에서 직접 확인해야 합니다."
- `scan_results`에서 다음을 **중립 라벨**로 표시
  - **돌파 확인가** = `close × (1 + upside_pct/100)` (60일 고가 추정)
  - **눌림 1차** = `buy1_price` (10일선)
  - **눌림 2차** = `buy2_price` (20일선)
  - **위험 기준가** = `stop_loss`
  - **추격 주의가** = `ma60 × 1.20` (이격 +20% 임계)
- 각 행에 분류 라벨(기회 후보 / 추격 위험 / 조건 부족) 표시
- 표 아래 각 라벨 의미 설명 + "관찰 보조 라벨이며 매매 권유가 아님" 재명시

### 📝 `/journal` — 매매일지 초안
- `stock_notes` 최근 30개 + 각 ticker의 최신 `scan_results` 컨텍스트를 카드로 묶음
- 카드 구성
  - 종목명/티커 → 단계 라벨 + 분류 라벨 + 관심도 + 내 판단
  - **스캔 컨텍스트(최신):** 종가·점수·이격·GC경과
  - **내가 기록한 관찰 기준:** 진입 관찰가 / 손절 기준 / 청산 관찰가 (DB 컬럼명 `target_buy/target_stop/target_sell`을 중립 라벨로 표시)
  - 한 줄 요약 + 자유 메모
- **새 DB 테이블 없음.** 기존 `stock_notes`·`scan_results`·`stocks`만 읽음
- 입력 폼 없음(읽기 중심)
