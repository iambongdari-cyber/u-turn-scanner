## 1. 작업 목적

v0.3-8까지 `/changes` 는:
- 헤더 + 비교 기준 강조박스
- 요약 6칸 (카운트만)
- v0.3-8 TOP10 4 카드 (리스트형, 종목 10개씩)
- 상세 표 (전체 1,000개+)

이 구성은 **상세는 풍부**하지만 "오늘 가장 두드러진 변화 종목 하나만 빨리 보고 싶다"는 사용 흐름에 한 번의 시선 이동이 더 필요했다. v0.3-9는 **단일 종목 highlight 4 카드**를 최상단에 두어 10초 안에 핵심 변화 종목을 파악할 수 있게 한다.

## 4. 4 카드 산출 기준

| # | 카드 | 필터 | 정렬(첫 항목 선택) | 표시 컬럼 |
|---|---|---|---|---|
| 1 | 🆕 **대표 신규진입** | `change_type === "NEW"` & `today_score` 가 number | `today_score` 내림차순 | 종목명 · 티커 / 현재 점수 / 현재 순위 / 섹터 / 단계 |
| 2 | ⬆ **최대 순위상승** | `rank_delta` 가 number이고 `< 0` | `rank_delta` 오름차순 (가장 음수가 가장 큰 개선) | 직전 순위 → 현재 순위 / 순위 변화 △ / 섹터 |
| 3 | ⬇ **최대 순위하락** | `rank_delta` 가 number이고 `> 0` | `rank_delta` 내림차순 (가장 양수가 가장 큰 하락) | 직전 순위 → 현재 순위 / 순위 변화 ▼+N / 섹터 |
| 4 | 📈 **최대 점수상승** | `score_delta` 가 number이고 `> 0` | `score_delta` 내림차순 | 직전 점수 → 현재 점수 / 점수 변화 +N |

### Fallback for 카드 1
NEW 종목 중 `today_score`가 null인 경우라도 카드가 표시되도록, 점수 픽 결과가 없으면 `today_rank` 오름차순으로 대체 픽한다.

## 6. graceful 처리

| 시나리오 | 동작 |
|---|---|
| 해당 카드 필터 결과 0개 | 본문에 "해당 없음" 회색 텍스트, 우측 메트릭 라벨 숨김. 안내문은 그대로 표시(레이아웃 일관성). |
| `change_dump_latest.json` 부재 / `status !== "ok"` | v0.3-7 기존 missing/error/not_enough_snapshots 분기 그대로 → v0.3-9 섹션 자체 미렌더 |
| `rank_delta` 가 number가 아닌 row | 카드 2·3 필터에서 제외 |
| `today_score` / `score_delta` 가 number가 아닌 row | 해당 카드 필터에서 제외 (카드 1은 rank fallback) |

모든 분기에서 throw 0건. 기존 v0.3-7 / v0.3-8 화면 기능 (요약 6칸 / TOP10 4 카드 / 상세 표 / 펼치기 / 하단 안내) **유지** ✓.
