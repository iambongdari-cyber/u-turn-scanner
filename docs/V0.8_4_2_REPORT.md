## 2. 최상단 요청문 추가 위치

`buildCombinedReport` 함수 첫 머리에 `CHATGPT_RECHECK_PROMPT` 상수를 push.

```ts
export const CHATGPT_RECHECK_PROMPT = `# ChatGPT에게 요청

U턴스캐너 리포트 분석해줘.

나는 직장인 초보 투자자이고, 장중 대응이 어렵습니다.

아래 리포트를 보고 내일 행동을 확실하게 정해주세요.

원하는 답변 형식:

1. 내일 매수 가능 / 보류 / 관망 중 하나로 결론
2. 볼 종목은 몇 개인지
3. 키움 예약매수를 넣어도 되는지
4. 시장가 매수 또는 추격매수 금지 여부
5. 손절가가 없으면 매수 금지 여부
6. 내가 실제로 해야 할 행동을 순서대로 지시
7. 마지막에 한 문장으로 결론

아래는 U턴스캐너 리포트입니다.`;

export function buildCombinedReport(judgment, detailed): string {
  const parts: string[] = [];
  parts.push(CHATGPT_RECHECK_PROMPT);   // ← v0.8-4.2 신규
  parts.push('');
  parts.push('---');
  parts.push('');
  parts.push(buildJudgmentReport(judgment));
  parts.push('');
  parts.push('---');
  parts.push('');
  parts.push('# 부록: 기존 상세 행동 리포트');
  ...
  parts.push(buildGptReport(detailed));
  return parts.join('\n');
}
```

- 상수는 `export const` 로 노출 — 단위 테스트나 다른 모듈에서 재사용 가능.
- 사용자 명세에 명시된 7 항목 형식을 글자 단위로 그대로 옮김.

## 3. 리포트 최종 구조

```
# ChatGPT에게 요청
U턴스캐너 리포트 분석해줘.
... (직장인 초보 + 답변 형식 7 항목)
아래는 U턴스캐너 리포트입니다.

---

# U턴스캐너 오늘의 판단 리포트
> 개인 기록용 AI 판단입니다.
> 자동매매가 아니며 실제 주문은 사용자가 키움에서 직접 입력합니다.
> 최종 판단은 사용자 본인 책임입니다.

## 1. 오늘 장 요약
## 2. 돈이 들어온 곳
## 3. 오늘의 1순위 종목
## 4. U턴스캐너 판단
## 5. 내일 행동 지시
## 6. ChatGPT에게 요청 (5문항 체크리스트)

---

# 부록: 기존 상세 행동 리포트
> 아래는 v0.7 까지 사용하던 상세 행동/보유/예약 점검 리포트입니다.

## 0. 오늘의 결론
## 1. 시장 상태
## 2. 전략 컨디션
## 3. 오늘 해야 할 행동
## 4. 오늘 하지 말아야 할 행동
## 5. 매매계획 기록 대상
## 6. 보유종목 점검
## 7. 예약매수 대기
## 8. 참고 후보 요약
```

- 최상단 ChatGPT 요청문이 리포트 전체 컨텍스트를 한 번에 설정.
- 그 아래 v0.8 판단 리포트가 핵심 데이터.
- 마지막 부록이 v0.7 상세 행동/보유/예약 점검(추가 맥락).
- 사용자는 textarea 전체를 복사해서 ChatGPT 에 붙여넣기만 하면 별도 지시 없이 7 항목 형식의 답변을 받을 수 있다.

## 4. PC/모바일 영향 여부

| 경로 | 영향 |
| --- | --- |
| PC: `/beginner` → "💬 GPT에게 다시 물어보기" 버튼 → 인라인 펼침 (`GptReportButton`) | `buildCombinedReport` 한 곳을 거치므로 자동으로 최상단 요청문 노출 |
| 모바일: `/beginner/gpt-report` SSR initialMarkdown | `buildCombinedReport` 사용 → 자동 적용 |

- 자동 복사 / 전체 선택 / 닫기 동작 변경 없음.
- 버튼 라벨 "💬 GPT에게 다시 물어보기" 그대로.

## 7. 테스트 방법

호스트:

```
npm run build
npm run dev
```

`/beginner` 접속 후:

1. PC 화면에서 "💬 GPT에게 다시 물어보기" 클릭 → 인라인 펼침 textarea 의 **첫 줄이 `# ChatGPT에게 요청`** 인지 확인.
2. 그 아래에 "U턴스캐너 리포트 분석해줘." + 직장인 초보 안내 + 답변 형식 7 항목이 그대로 있는지.
3. 7 항목 뒤에 `---` 가 있고, 그 아래에 `# U턴스캐너 오늘의 판단 리포트` 가 이어지는지.
4. 판단 리포트 §1~§6 까지 모두 있는지.
5. 그 다음 `---` 와 `# 부록: 기존 상세 행동 리포트` 가 있고, 부록 §0~§8 이 그대로 붙는지.
6. [자동 복사 시도] 후 ChatGPT 에 붙여넣기만 해도 별도 지시 없이 7 항목 형식 답변을 받을 수 있는지.
7. 모바일 폭(< 768px) 으로 줄여서 모바일 링크 클릭 → `/beginner/gpt-report` 진입 → 본문 `<pre>` 의 첫 줄도 동일하게 `# ChatGPT에게 요청` 인지.
8. 모바일에서도 부록까지 완전한 구조가 그대로 노출되는지.

### 샌드박스 검증 제약
이전 단계와 동일하게 mount 캐시 stale 가능성. 호스트 측 `npm run build` 통과로 최종 확인 부탁드립니다. Read tool 로 확인한 변경 코드는 단순 텍스트 push 추가뿐이라 빌드 실패 가능성은 낮습니다.
