> **목표:** 홈 최상단(`SidecarFreshnessBox` 직후)에 "✨ 오늘 한 줄 요약" 박스 추가. 첫 화면에 핵심 정보(카운트 5종 + 강한 후보 + 기준일)를 한눈에 노출.

## 1. 작업 목적

v0.3-16까지 홈은 5 카드(대표 사건) + 3 카드(추가 확인 후보)로 풍부해졌지만:
- 모바일 첫 화면(~700px)에는 SidecarFreshnessBox + HomeSummaryCard 일부만 노출
- 5 카드가 한 줄에 들어가는 lg(1024+)에서도 3 카드 영역까지 보려면 스크롤 필요
- 향후 시장 경고 / 섹터 변화 카드 추가 예정 → 첫 화면 인지도 더 어려워짐

기존 JSON 키를 TS 인터페이스에 노출 (compare_snapshots.py v0.3-7부터 존재하는 키, 본 작업에서 새 키 요구 0건):

interface ChangeDumpLite {

    n_score_up?: number;

### 3-3. `TodaySummaryLineBox` 컴포넌트 신규 (파일 끝, 약 80줄)

#### 데이터 의존 (이미 계산된 값 재사용)
| 의존 | 출처 | 추가 fetch / 계산 |
|---|---|---|
| `dump.summary.*` | v0.3-7부터 JSON에 존재 | **0건** (인터페이스 확장만) |
| `secondLookPicks.topConsistent/topMomentum/topUTurnStrong` | v0.3-15/16에서 이미 계산 | **0건** |
| `dump.today_date / previous_date` | v0.3-7부터 존재 | **0건** |

#### 표시 구조

| 영역 | 내용 |
|---|---|
| **헤더 좌** | "✨ 오늘 한 줄 요약" (amber-900) |
| **헤더 우** | "기준일 \<today_date\> · 비교 \<previous_date\>" (amber-700) |
| **카운트 라인** | "신규 N · 순위↑ N · 순위↓ N · 점수↑ N · 이탈 N" |
| **강한 후보 라인** | "강한 후보: \<3 카드 종목명 truthy 만\>" + 우측 "자세히 보기 →" `/changes` |
| **안전 안내** | "한눈에 보기 위한 요약입니다. 매수 추천이 아니라 관찰 보조 정보..." |

#### graceful 처리
- `dump` 부재 또는 `status !== 'ok'` → 박스 자체 미렌더 (SidecarFreshnessBox / HomeSummaryCard 가 이미 안내)
- `summary` 부재 → 박스 자체 미렌더
- 3 카드 모두 null → 강한 후보 라인 미렌더

#### 시각 톤
- amber 톤 (`border-amber-200 bg-amber-50/40`) — 다정한 첫 시선
- 박스 자체는 작음 (~80px 높이)
