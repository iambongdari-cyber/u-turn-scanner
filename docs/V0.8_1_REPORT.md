## 2. 신규 lib 함수 설명

### 2-1. `market_strength.ts`

**`judgeMarketStrength(market: ScanMarketRaw): MarketStrength`**

입력: `scan_dump.market` 의 `kospi_above_ma60` / `kosdaq_above_ma60` / `kospi_20d_return` / `kosdaq_20d_return` 4 필드.

판단 (사용자 명세 §2 그대로):
- `above_ma60 === true` + `ret20d ≥ 3` → STRONG
- `above_ma60 === false` + `ret20d ≤ -3` → WEAK
- 그 외 → NEUTRAL

KOSPI vs KOSDAQ 상대강도:
- `kospi_20d - kosdaq_20d ≥ 3` → KOSPI_LEAD
- 반대 → KOSDAQ_LEAD
- 그 외 → BALANCED

데이터 부족 (4 필드 중 하나라도 null) → `insufficient: true` + narrative "시장 흐름 데이터가 부족해 보수적으로 판단합니다."

자연어 narrative 매트릭스 (8 분기):
- "KOSPI 와 KOSDAQ 모두 강한 흐름입니다."
- "KOSPI 는 강하지만 KOSDAQ 은 약합니다." 등

**`judgeCapStyle(strength): CapStyle`**

v0.8-1 단순 기준 — 상대강도 기반:
- KOSPI_LEAD → "대형주 중심의 장세입니다."
- KOSDAQ_LEAD → "중소형주 중심의 장세입니다."
- BALANCED → "대형주·중소형주 흐름이 혼재되어 있습니다."

(정밀 시가총액 기반 분류는 v0.9+ 별도 fetch.)

### 2-2. `tomorrow_action.ts`

**`buildTomorrowAction(input): TomorrowAction`**

입력:
- `regime: MarketRegime` (BULL/NEUTRAL/BEAR/DANGER/UNKNOWN)
- `conditionState: 'DATA_INSUFFICIENT' | 'EXCELLENT' | ... | 'DANGER'`
- `topPickName: string | null` (selectedNewTargets[0]?.name)
- `hasHoldingOrReserved: boolean`
- `strongCandidateCount?: number` (강세장 캡 확대 판단용)

분기 (사용자 명세 §3 그대로):

| 분기 우선순위 | 조건 | maxNewCount | intensity | summaryLines |
|---|---|---|---|---|
| 1 | 시장 = DANGER | 0 | NONE | "내일은 신규 진입하지 마세요." |
| 2 | 컨디션 = DANGER | 0 | NONE | "전략 컨디션이 위험이므로 신규 진입을 보류하세요." |
| 3 | 시장 = UNKNOWN | 0 또는 1 | LIGHT | "데이터가 부족해 보수적으로 판단합니다." |
| 4 | 시장 = BEAR | 0 또는 1 | NONE/LIGHT | "신규 진입보다 보유종목 점검이 우선입니다." |
| 5 | 시장 = NEUTRAL | 0 또는 1 | NONE/LIGHT | "1순위 1 개만 보세요." |
| 6 | 시장 = BULL + 보유/예약 있음 | 1 | NORMAL | "강세장이지만 보유/예약이 있어 신규는 1 개로 제한." |
| 7 | 시장 = BULL + 보유/예약 없음 + strong 후보 ≥2 | 2~3 | NORMAL | "최대 N 종목 검토 가능." |
| 8 | 시장 = BULL + 그 외 | 1 | NORMAL | "1순위 우선 검토." |

금지 행동 기본값:
- 손절가 없는 매수 금지
- 테마주 추격 금지
- 동시 다종목 매수 금지

추가 분기:
- 위험구간 → "위험구간에서 신규 진입 금지"
- 약세장 → "약세장에서 무리한 반등 매수 금지"
- 강세장 → "추격매수 금지 (이격 12% 이상 보류)"

## 4. 데이터 fallback 처리

| 부족 | 처리 |
|---|---|
| `kospi_above_ma60` 또는 `kosdaq_above_ma60` 누락 | `IndexStrength = NEUTRAL` |
| `kospi_20d_return` 또는 `kosdaq_20d_return` 누락 | `IndexStrength = NEUTRAL` + `relative = BALANCED` |
| `market` 객체 자체 누락 | `MarketStrength.insufficient = true` + narrative "시장 흐름 데이터가 부족해 보수적으로 판단합니다." |
| `marketRegime = UNKNOWN` | `TomorrowAction` 분기 §3 — 1순위 있으면 1 개 (LIGHT), 없으면 0 개 |
| `topPickName = null` (1순위 없음) | 약세장/보합장에서 "신규 진입보다 관망이 우선입니다." / 강세장에서도 "관망이 우선" |
| `conditionState = DATA_INSUFFICIENT` | 시장 상태 기준 분기만 적용 (컨디션 DANGER 분기 미적용) |
| `regime = null` (사이드카 자체 부족) | CoachShell 안 조건부 렌더 — `<MarketFlowBox />` 미표시 (안전) |

UI 안내:
- `marketStrength.insufficient === true` 시 카드 헤더 아래 "※ 일부 시장 데이터가 부족해 보수적으로 판단합니다." 표시
- 어떤 경우에도 에러 throw 없음 — 모든 경로가 자연어로 fallback
